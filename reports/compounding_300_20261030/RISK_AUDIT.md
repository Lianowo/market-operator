# 风险档位与去头部口径核对

日期：2026-10-30。未修改生产配置或策略源码，只新增离线对照脚本及结果。

## 历史 ex10 不是去头部10%

`git show 49c066f:scripts/_diag_struct_confirm.py` 和 `_diag_cascade_impulse.py` 的统计代码均为：

```python
sp = sorted([float(t["net_pnl"]) for t in cl], reverse=True)
ex10 = sum(sp[10:]) if n > 10 else 0.0
```

因此历史“去Top10 / ex10”只去最大10笔，不是10%。既有精确对照报告 `reports/parity_49c066f_20261030_221913/summary.md` 证明当前重构与49c066f在常规配置六场景的逐笔、权益、计数器一致；该证据不覆盖动态风险场景。

结论：

1. “去头部10%仍正”的说法不符合49c066f历史诊断的实现。常规配置真正去10%（67笔）也是负数，不是新档位才出现。
2. 新档位相对旧动态档位，最大回撤23.15%升至58.72%，在本次受控回放中由阈值变化及其下游仓位/容量/复利路径引起。
3. 同样7500 USDT现金，旧档位风险率1%，新档位3%；同样2500现金，旧1%，新4%。高风险持续到更大本金，盈利和亏损一起放大。
4. 风险率变化不只是把每笔净利润乘常数。权益路径、档位匹配、最小步长、杠杆/容量准入均可改变交易集合：旧706笔、新688笔；容量拒绝旧2、新38。
5. 新档位最大回撤：2026-02-15 07:00 UTC权益8893.96，至2026-08-16 21:00 UTC权益3671.80，回撤58.72%。包含浮盈回吐，不是只按现金结算亏损算回撤。
6. 去头部是原账本收益归因，不是删除交易后重新复利。头部按绝对净利润排序受本金随时间变化影响。

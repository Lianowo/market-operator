## ② 历史事实反事实(10-11 06:33 → 10-25 06:33)

### 账 1:入场记账(参考价 `ref` vs 真实成交)

| 指标 | 值 |
|---|---|
| 不利偏移 bps | 均值 **+23.33** / 中位 **0.00** / p90 **+127.83** / 最差 **+281.54** / 最好 −99.13 |
| 名义额绝对误差 USDT | 均值 +0.044 / 中位 −0.060 / 区间 −0.783 … +1.443 |
| 名义额相对误差 % | 均值 0.76 / 中位 0.59 / p90 1.28 |

结论分两层,必须分开说:

- **不改变钱**:实现盈亏由交易所成交决定,记账用参考价还是成交价,USDT 盈亏一分不差。
  所以这条改动**不是收益改动**,不能拿"净收益"来判它。
- **改变风险口径**:`entry` 同时是 `initial_risk` 的分母与 R 的基准。10 笔里中位 0 bps
  (多数字段无误差),但尾部 3 笔(DOGE +281 bps、ARB +128、JCT −99)让"以为的风险"
  与"实际的风险"差到 1.3%(p90)。**判定:必要且已证非零**,但量级是小尾部的,
  不值得为它单独等实盘样本。

### 账 2:保护单被拒 —— 三类,处置完全不同(本次回放把原来的说法推翻了)

| 分类 | 条数 | 报错时仓位是否还在 |
|---|---|---|
| `43023 仓位不足`(交易所已无仓) | 4 | 否(10-24 15:19 已平,15:21–15:23 仍在重挂) |
| `45122 价格已穿越` | 4 | 否(10-24 14:18 已平,14:19–14:22 仍在重挂) |
| 其它 | 0 | — |
| **真正"仓位还在、保护单被拒"** | **0** | — |

推翻的旧说法:`reports/live_diagnosis_20261025.md §6(b)` 原先写"1000BONK 触发价已在错误一侧 ⇒ 交易所必然拒单,
机器人重试后按已越线市价离场"。回放显示那 4 条其实是 **`43023` 无仓拒单**,那笔 −4.493
是在报错**之前**(15:19)按正常离场路径平掉的。8 条拒单**全部**发生在交易所已平仓之后,
是本地状态残影,不是"持仓裸奔"。

由此产生两处**由证据驱动的代码修正**(本次新增):

1. `_stop_reject_no_position`:命中 `43023/仓位不足/no position` ⇒ 只丢本地止损记录,
   交给 `reconcile` 收尾,**不发市价单、不误报"仓位仍在,人工核查"**。
2. `_mark_from_reject`:越线判定改用**交易所报文里自己报的标记价**
   (`…止损价格请>标记价格 0.34387`),而不是最多 2 分钟前的本地 `mark`;
   取不到才回退本地值。

**判定:原分支的"收益"未证(样本 0),但它会误伤 —— 8/8 事件都会朝一个不存在的仓位
发平仓单;修完后误触发面归零,而有仓场景下的纪律不变。**

### 账 3:日损熔断跨日锚(用**真实 `DailyLossBreaker`** 回放 10-25 的重启事实)

| 口径 | 当日锚 | 熔断线(−10%) |
|---|---|---|
| 修前(锚 = 当日首个 tick) | 100.3977 | 90.3579 |
| 修后(锚 = 上一日最后一笔) | 107.6677 | 96.9009 |

- 10-24 收盘 107.6677 → 10-25 05:37 重启权益 100.3977,缺口 **7.2700 USDT(−6.75%)**;

**判定:已证**。这条不是"更好",是"原本没有生效":缺口亏损在旧口径下不计入任何日预算。

## 为什么这些判定不能等实盘

- **事件率**:14 天里"有仓 + 保护单被拒"是 **0 次**,再跑 14 天大概率还是 0 —— 等不到,
  等到了也是拿真钱换一条本该由日志证伪的结论。
- **反事实不需要新样本**:账 1 用的是**同一批成交**的两种记账,账 3 用的是**同一组事实**
  喂给修前/修后两个真实类。样本量固定,结论不随等待时间变化。
- **策略级结论才需要新样本**:任何"改期望值"的改动(含 `max_daily_loss_frac` 10%→5%、
  `turtle_stop_atr` 2.0→2.5、D1)必须走 `reports/prereg/20261025_a3_universe_slippage.md`
  的口径与闸门,先离线 M0 复现,再谈参数。

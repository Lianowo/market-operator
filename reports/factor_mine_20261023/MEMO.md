## 0. 先回答两个问题

**Q1「不同时间尺度用不同的出入场/持仓管理方式」——数据支持哪一半?**

支持「不同的**选择性**与**成本结构**」,**不支持**「不同的**出场形状**」:

- 出场形状(止盈/保本/半仓/时间帽)在 4 个周期 × 2 段 = 8 格里**没有一条全为正**;
  最接近的是 `tl12`(12 根 TF bar 后若 MFE<0.5R 就离场):8 格中 6 正 2 负,
  负的两格也只有 −0.005/−0.007,正的一侧 +0.005…+0.034 R。
- 入场选择性(顺/逆更粗周期)在 **2h 与 4h/12h 上方向相反**,且 dev/test 同向。
- 成本结构 4 个周期**完全不同**:同样 1R 风险下的名义是 55×/40×/25×/19×;2h/4h 的成本
  73%/71% 是手续费,12h/1d 的最大项仍是手续费(65%/60%)但资金费随持仓时长升到 13%/19%。
  真正分化的是**毛**:12h 原始毛只有 0.068R(4h 的 19%),净 E[R] +0.021,全场最薄 ——
  这本身就是"分周期管理"最正当的理由(成本口径已在 §2 用实盘数据订正)。

**Q2「挖能提高胜率和盈亏比的因子」——挖到了什么?**

## 4.5 12h/1d 的胜率与盈亏比:是"入场选择"还是"出口几何"?(2026-10-23 追加)

只读诊断,复现 `python scripts/_diag_tf_quality.py`,明细 `reports/tf_quality_20261023/`
(`QUALITY.md` / `quality.json`)。本节的 E[R] 一律是**纯几何毛 R**(不含任何成本),
因此与 §2 的净口径不冲突、可相加;反事实全部在每笔自己的 1h 路径上重放,
同一根 bar 同时触到止损与止盈时按**先触止损**处理(对止盈规则偏保守)。

**结论先行**

1. **不是"方向选错"**。12h/1d 到达 +1R 的比例是四个周期里最高的
   (12h 38.6% 两段一致;1d dev 48.6%,对比 2h 34.8% / 4h 34.1%),
   但"到过 +1R 却收在亏损"的比例同样最高(dev 段转化率 **68.1% / 70.6%**,
   对比 2h 86.0% / 4h 77.4%)。胜率缺口的主体是这一步转化,不是入场方向。
2. **回吐幅度与风险单位成反比 —— 这是 12h/1d 盈亏比差的机械原因,而且可以直接量出来**。
   现行 §8.3 只在"新确认逆向枢轴"处收紧防线(枢轴外侧 ± 0.1 ATR),所以回吐的**价格尺度
   大致恒定**:8 个 TF×段格的中位回吐全部落在 **1.54–2.05 ATR**(dev/test:
   2h 1.76/1.74、4h 1.91/2.05、12h 1.72/1.74、1d 1.54/1.78)。变的是风险单位 `rp`:
   12h/1d **1.38 / 1.17 ATR**(REJECT 用结构止损),2h/4h **2.12 / 2.08 ATR**(2·ATR turtle)。
   同一个 ATR 回吐除以更小的 rp ⇒ R 口径回吐 **1.21 / 1.23R** vs **0.87 / 0.97R**。
   同一件事的另一面是"满损占比":12h/1d 的亏损笔里 56% / 64% 是 ≤ −0.95R 的整段止损,
   2h/4h 只有 37% / 32% —— rp 小,噪音就够打到 −1R。
3. **12h 的目标距离是 2h/4h 的 1.5 倍**。四个周期的箱宽几乎一样(≈8 ATR),
   但结构止损 12h 只有 1.29 ATR ⇒ 12h 的 E3 到箱体对侧缘的目标中位 **3.8R**
   (2h/4h 2.5R / 2.5R)。把 12h 全体按目标距离代理三分位(边界取 dev 分位、test 原样套用),
   毛E[R] = dev **+0.06 / −0.16 / −0.46**、test +0.09 / +1.10 / **−0.08**:
   最远的那一档(约 1/3 的交易)两段都不赚。
4. **12h 与 1d 的病因不同,不能一起改**:
   - **1d = 好交易被几何截断**。无止损、持有 20 根 TF bar 的原始边缘 **+0.56R**
     (95%CI −0.14…1.21),ATR 口径 +0.69 ATR / 正漂移占比 55–57%,是四个周期最强;
     而实际毛 +0.266R 已经贴着"k=1 止损 + 无 TP"的理论上限 **+0.274R**。
     它的低胜率与 1.44 盈亏比是 rp=1.1 ATR 的必然结果,**不是缺陷**。
   - **12h = 没有可收割的 alpha**。20 根窗口的价格漂移均值 **−0.16 ATR**
     (中位 −0.20 ATR),正漂移占比 48.8%;止损宽度 k=1…3 × 止盈 1/2/3R 的
     20 格网格里,**最好一格 +0.055R,所有带止盈的格子全为负**。出口机制救不了它。

## 9. 追加:每尺度"最优路径"搜索(2026-10-23,119 格 × 4 尺度)

**问题**:先给 2h/4h/12h/1d **各自**找一条使胜率/盈亏比/净 R 同时最好的路径,再把四者组合。
全文见 `reports/tf_opt_20261023/OPTPATH.md`;脚本 `scripts/_diag_v21_tf_opt.py`(只读)。

**方法**:每 TF 119 格,维度全部是 config 已有且 **per-TF 可配**的字段
(入场闸 4 键 + 出口几何 `k_is / turtle_stop_atr / reject_target_mode / reject_use_struct_stop`)。
单尺度 = 该 TF 独占 300U 与全部预算(口径同 `tf_solo_20261023`)。**dev 选、test 只报告**。

|---|---|---|---|
| 2h | +0.061 / +0.008 / +0.044 / +0.004 | +0.104 / +0.001 / +0.068 / +0.016 | 无可识别改进；成本吃掉 62% 毛利 |
| 4h | +0.070 / **+0.468** / +0.209 / +0.168 | +0.295 / +0.055 / +0.208 / +0.154 | dev 调参打掉 0.41R OOS |

**四条新增结论(与 §3/§4.5 不冲突,是独立证据)**

1. **"胜率与盈亏比同时最优"在定义上不成立**:`PF = WR/(1−WR)·payoff`,两者是同一坐标轴,
   提高一个必然压低另一个。真正的两个自由度是 **PF** 与 **净 E[R]**。
2. **dev 选优系统性降低 OOS**:4h 的 dev-top10 在 test 上中位数 +0.069(基线 +0.468)、
   1d +0.028(基线 +0.190);12h 的最优结果就是"什么都不做"。⇒ 这份样本上 per-TF 调参
   的期望值为负。
3. **出场几何是死路(第二种证据)**:17 条出场规则 × 4 TF × 2 段里,**加 TP 的 40 格只有
   1 格相对实际略好(+0.011R)**;两段同时优于实际出场的只有 3 条,幅度 ≤ +0.03R,
   小于 CI 一个数量级。12h 一条都没有。
4. **"四个最优拼起来最差"是可加算术,不是组合出了新问题**:test 段逐尺度 ΔE[R]
   (−0.008 / −0.413 / −0.160 / −0.054)按 a0 的风险权重(48/24/19/9%)相加
   = **−0.148**,实测 −0.148(`best_all` test +0.002 vs `a0` +0.149);其中 **4h 一格占 62%**。
   崩的是毛利(gross 0.232→0.079),成本几乎不变(0.102→0.096)。
   ⇒ 不是"噪声不叠加",而是**四项各自为负、且由同一 dev 窗口同一个赌注产生,不能互相抵**。
5. **"共享账户挤掉 0.03~0.08R"是错误归因(已更正)**:`--stage crowd` 用同一批 a0 参数、
   只改"别的尺度在不在场"实测(`tf_opt_20261023/crowd.json`):
   - a0 共存 **811 次 cap_skips 全是 `TF_CAP`,`PORTFOLIO_CAP` = 0**;`best_all` 970 次同样;
     准入时刻 `admission_full_cost` 只返回周期池,且 4×2.25% = 9% < 12% ⇒ 账户池永不触发。
   - 并发峰值 13、**每尺度 4 个,与独占账户完全相同** ⇒ 别的尺度在场时槽位一个不少。
   - 放开容量(`loose`)反而更差:n 1440→1643、E[R] 0.0875→0.0726 ⇒ 容量闸是**尺度内筛选**,不是挤占。
   - 真实耦合 = **共享权益 ⇒ 同笔 `risk_usdt` 差 27%~50%**(E[R] 按风险加权)+ 最小手数粒度;
     账户口径四尺度几乎完全可加(独占 net 之和 381.76 vs 共存 380.07,−0.4%),但单尺度净额
     不可相加(1d 45.05→12.70、4h 160.04→201.05,钱在尺度之间搬家)。
   - 真正的"挤占"是**风险相关性**:同币跨尺度同时持仓占持仓时长 **53.7%**(放开容量后 63.7%),
     一次 4% 下跌同时打掉 BTC 四个止损 = 3% 权益。详见 OPTPATH.md §5.5。

**成本档横向比较必须先做同集反事实(方法学修正)**:
1.0× 与 1.5× 的回放会因复利路径不同而换掉一部分交易(12h/1d 重叠仅 83–97%),
1d 的 11 笔非交集交易几乎贡献全部毛利。用 `net(m)=gross−m·cost` 在同一交易集上重算后,
**1d 在 1.5× 下的真实结构优势只有 +0.007R(不是 +0.171R)**;`--stage decomp` 产出
`reports/tf_opt_20261023/decomp.json`。

**唯一有机制的候选**:1d
`min_box_rotations 2→0 / min_box_quality 0.40→0.60 / zone_cooldown_bars 2→0 /
turtle_stop_atr 2.0→2.5 / reject_target_mode opposite→mid /
reject_use_struct_stop true→False`
—— full@1.0 −0.010、**cost/R 0.074→0.039(成本占毛利 30%→19%)**、WR 0.383→0.503、
payoff 2.21→1.77、N 128→147。机制:止损 2.0→2.5ATR + 关结构止损 ⇒ 名义/风险
**17.6×→8.9×** ⇒ 费率/滑点/资金费按 R 计同步减半。

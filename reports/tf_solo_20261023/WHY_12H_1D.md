# 为什么 12h / 1d 单独回放不为正（2026-10-23）

**范围**：只读归因，解释 `RESULTS.md` 里 12h / 1d 单尺度负数。不改 `config/`、不改 `src/`、
不新增裁决结论。所有数字可由 `scripts/_diag_v21_tfsolo.py` + 本文 §11 的归因口径复现。

---

## 0. 一句话

**12h / 1d 不是"被成本吃掉"，而是"在 dev 段的毛边缘本身≈0"**：毛 E[R] 只有
+0.028 / +0.021，而跨所有周期的成本地板恒为 0.075–0.094R ⇒ 净额必然转负。
毛边缘≈0 的机制有两条，且都能逐笔量化：
(1) **无目标位、纯追踪止损** ⇒ 到过 +1R 的单只捕获 31%–35%，平均回吐 2.0R；
(2) **止损≈0.8σ(持仓期) + dev 段漂移统计上为 0** ⇒ **42% 的交易直接打满初始止损**。

---

## 1. 先把三段补齐（新增 test 段实测）

之前只有 dev / full，test 由 `full − dev` 推断（不严谨，两次运行的账户路径不同）。
本轮补跑 `--segments test`，三段都是实测：

`explore`（BTC/ETH/SOL，@1.0x，净额 USDT / E[R]）：

| TF | dev（2024-10→2026-03, 502d） | test（2026-03→2026-10, 216d） | full |
|---|---|---|---|
| 2h | 329 / **+58.8** / +0.085 | 153 / +8.8 / +0.027 | 482 / +70.8 / +0.065 |
| 4h | 181 / **+38.8** / +0.103 | 74 / **+118.9** / **+0.657** | 255 / +175.6 / +0.302 |
| 12h | 221 / **−14.1** / **−0.036** | 79 / **+54.3** / **+0.333** | 295 / +51.5 / +0.095 |
| 1d | 69 / **−6.3** / **−0.053** | 39 / +14.6 / +0.195 | 107 / +10.6 / +0.056 |

读法：**12h / 1d 的"不为正"只发生在 dev 段**；full 段两者都是正的。所以问题不是
"这两个周期没有边缘"，而是"这两个周期只在 test 那 216 天里有边缘"。

> 注意 dev 有 502 天、test 只有 216 天，所以 dev 的 N 大约是 test 的 2.3–2.8 倍
> （按年化笔数其实相近：12h 161 笔/年 vs 133 笔/年）。**dev 用更多样本、更长时间，
> 只测到 0 边缘。**

## 2. 成本地板：跨 TF 几乎恒定，只是结构互换

成本拆成 R（费用 / 资金费 / 滑点，均除以 Σrisk_usdt）：

| TF | 段 | 毛 E[R] | 费用R | 资金费R | 滑点R | **成本R** | 净 E[R] |
|---|---|---:|---:|---:|---:|---:|---:|
| 2h | dev | +0.158 | 0.061 | 0.012 | 0.020 | **0.093** | +0.085 |
| 2h | test | +0.122 | 0.081 | 0.014 | 0.027 | **0.122** | +0.027 |
| 4h | dev | +0.166 | 0.046 | 0.017 | 0.015 | **0.078** | +0.103 |
| 4h | test | +0.742 | 0.058 | 0.027 | 0.019 | **0.105** | +0.657 |
| 12h | dev | **+0.028** | 0.032 | 0.032 | 0.011 | **0.075** | **−0.036** |
| 12h | test | +0.414 | 0.035 | 0.047 | 0.012 | **0.093** | +0.333 |
| 1d | dev | **+0.021** | 0.024 | **0.050** | 0.008 | **0.081** | **−0.053** |
| 1d | test | +0.281 | 0.024 | **0.062** | 0.008 | **0.094** | +0.195 |

三条可直接引用的事实：

1. **成本地板 ≈ 0.075–0.094R，对四个周期、两个段都成立**（唯一波动来自段内止损宽度差异）。
   慢周期**没有**拿到成本优势。
2. 但**成本结构随持仓时长互换**：费用+滑点从 2h 的 0.081R 降到 1d 的 0.032R
   （止损变宽 ⇒ 同样风险下名义额变小），而**资金费从 0.012R 涨到 0.050–0.062R**
   （1d 中位持仓 132–182h ≈ 16–23 个 8h 结算点）。**1d 的资金费占总成本 62%–66%。**
3. ⇒ **12h / 1d 的盈亏平衡线 = 毛 E[R] ≥ 0.08**。dev 段实测 0.028 / 0.021，
   **只覆盖成本的 37% / 26%**，所以净负是算术必然，不是运气差。

## 3. 机制 A：无目标位 + 追踪止损 ⇒ 捕获率 31%–47%

退出原因统计（explore，全部四周期）：

| TF | dev | test | 止损被上移过 |
|---|---|---|---|
| 2h | PROTECTIVE_STOP 322 + §8.5 7 | 150 + 3 | 260/322 |
| 4h | 175 + 6 | 73 + 1 | 146/175 |
| 12h | 217 + 4 | 76 + 3 | 134/217 |
| 1d | 67 + 2 | 39 + 0 | 41/67 |

**四个周期都没有任何"目标位 / 止盈"退出**：98% 以上的退出都是 PROTECTIVE_STOP 追踪止损
（其余是 §8.5 规则平仓）。止损位实际被上移过的比例（dev 段）：2h 81%、4h 83%、12h 62%、1d 61%。
收益结构因此完全由"趋势还能跑多远"决定。用 1h 原始 K 线重建 MFE/MAE（以初始止损距为 1R）：

| TF | 段 | MFE 中位 | ≥1R 占比 | MAE ≤ −1R 占比 | **捕获率** | 回吐R | 亏单中位止损时长 |
|---|---|---:|---:|---:|---:|---:|---:|
| 2h | dev | 0.72 | 41% | 24% | 40% | +1.63 | 3h |
| 2h | test | 0.65 | 33% | 32% | 45% | +1.78 | 5h |
| 4h | dev | 0.73 | 41% | 20% | 42% | +1.56 | 7h |
| 4h | test | 0.76 | 43% | 19% | 52% | +2.23 | 10h |
| **12h** | **dev** | 0.70 | 42% | **42%** | **35%** | +2.02 | 22h |
| 12h | test | 0.96 | 49% | 28% | 47% | +1.66 | 28h |
| **1d** | **dev** | 0.99 | 49% | **42%** | **31%** | +2.03 | 59h |
| 1d | test | 0.79 | 38% | 18% | 49% | +1.69 | 47h |

`捕获率` = 在到过 +1R 的样本里，实现 R 之和 / MFE 之和。
`回吐R` = 同一批样本里 (MFE − 实现) 的均值。

**回吐的直接金额**（到过 +1R、最终收在 ≤ +0.1R 的"过山车"）：

| TF | 段 | 过山车笔数 | 占全部 | 其 MFE 合计 | 其实现合计 | **净丢** | 该段净 ΣR |
|---|---|---:|---:|---:|---:|---:|---:|
| 12h | dev | 30 | 14% | +51.1R | −18.2R | **+69.3R** | −11.8R |
| 1d | dev | 12 | 17% | +19.6R | −8.5R | **+28.1R** | +0.2R |
| 2h | dev | 29 | 9% | +42.3R | −10.3R | +52.6R | +33.2R |
| 4h | dev | 24 | 13% | +31.8R | −7.9R | +39.7R | +20.0R |

**12h 在 dev 段光是"到过 +1R 又全吐回去"就丢了 69.3R，而该段净额只有 −11.8R。**
1d 同段丢 28.1R、净额 +0.2R —— 即 **1d 的全部毛利被这条通道抵掉了**。
（2h/4h 也回吐，但它们靠短持仓的高频往返把毛利做了 20–33R，所以仍是正的。）

---

## 4. 机制 B：止损 ≈ 0.8σ(持仓期) + 零漂移 ⇒ 42% 打满止损

止损宽度与"持仓期应有波动"的关系（stop% = risk/notional，σ_hold = 年化波动 × √(持仓/8760)）：

| TF | 段 | 止损% 中位 | 持仓中位 | **止损 / σ(持仓期)** |
|---|---|---:|---:|---:|
| 2h | dev | 2.45% | 14h | 0.96 |
| 4h | dev | 3.22% | 27h | 0.87 |
| 12h | dev | 4.55% | 61h | 0.80 |
| 1d | dev | 6.03% | 132h | **0.72** |

止损基本被标定在"持仓期 1σ"附近（快周期 0.87–0.96，慢周期 0.72–0.82，慢周期相对更紧）。
在**无漂移**的随机游走里，先打到 −0.8σ、后打到 +1σ 的概率约 0.8/(0.8+1) ≈ 44%。
**dev 段 12h/1d 实测"打满初始止损"的比例正是 42%** —— 与"漂移=0"的理论值几乎重合。
这不是参数错，是**趋势系统在没有趋势的市场里的应有表现**：赚不到 R，只付出成本。

## 5. 机制 C：dev 与 test 是两个不同的市场

（1h 收盘；`漂移 t` = ln(净变)/Σ|逐根变| × √N，等价于漂移量的 t 值）

| 段 | 窗口 | BTC | ETH | SOL | 年化波动（BTC/ETH/SOL） |
|---|---|---|---|---|---|
| dev | 2024-10-20 → 2026-03-14 | +6.2% | **−18.9%** | **−42.5%** | 46.8% / 71.4% / 84.9% |
| test | 2026-03-14 → 2026-10-20 | +16.8% | +16.2% | +19.7% | 38.1% / 51.1% / 56.8% |

| 段 | 漂移 t（BTC / ETH / SOL） |
|---|---|
| dev | +0.17 / −0.38 / −0.80 |
| test | **+0.81 / +0.61 / +0.61** |

- dev：三币方向不一致（BTC 平、ETH/SOL 跌），漂移 t 绝对值 ≤ 0.8，**波动反而更高**。
- test：三币同向上涨，漂移 t 0.6–0.8，**波动更低** ⇒ 对"追踪止损 + 长持仓"最有利的形态。

方向层面的印证（12h）：dev 多头毛 E[R] **+0.000** / 空头 +0.062；test 多头 **+0.809** /
空头 +0.003 —— **edge 完全跟着"哪边在走趋势"搬家**，不是稳定的双向边缘。
1d 同样翻转：dev 多头 −0.108 / 空头 +0.187；test 多头 +0.451 / 空头 −0.054。

---

## 6. 为什么 2h / 4h 不受影响

- 持仓 14h / 27h（12h 61h、1d 132h），**暴露在漂移上的时间短**；
- 它们吃的是箱体往返（entry 在箱边、trail 在箱内），**不需要大漂移**；
- 因此 dev 段的"漂移=0"对它们是中性偏正（2h +0.085 / 4h +0.103），
  而同样的条件对 12h/1d 是致命的（止损距离被 61–132h 的噪声撑开，价格必须先走出
  4.5%–6% 才到 +1R）。

一句话：**12h/1d 的收益是"趋势持续性"的函数，2h/4h 的收益是"箱体往返频率"的函数。**
dev 段前者=0，后者正常。

## 7. 统计现实：这些都还不能叫"证明"

按笔 bootstrap（3000 次重采样）的 95% CI（净额）：

| TF | dev | test |
|---|---|---|
| 2h | +58.8 [−36.2, +161.1] | +8.8 [−76.6, +113.8] |
| 4h | +38.8 [−38.7, +129.4] | +118.9 [−10.3, +293.1] |
| 12h | −14.1 [−98.2, +78.9] | +54.3 [−13.3, +141.2] |
| 1d | −6.3 [−45.9, +39.5] | +14.6 [−26.5, +67.4] |

**全部区间都含 0。** 正确的表述是：

- 12h：dev 段测得 0 边缘（点估计 −0.036R，CI 宽 ±0.4R），**不是"证明无边缘"**；
- 12h/1d 的 full 段正值，其权重实际由 test 段贡献（test 毛 E[R] +0.414 / +0.281）；
- 1d 只有 69 / 39 笔，持仓 5.5–7.6 天、资金费 0.05–0.06R/笔 ⇒ 当前样本量不足以把这层差异分辨出来。

**1d 还多一层脆性**（成本覆盖倍数）：full@1.0x 毛 0.134 / 成本 0.087 = **1.55x 覆盖**；
full@1.5x 毛 0.103 / 成本 0.130 = **0.79x** ⇒ 净额从 +10.6 翻到 −2.9。
12h 的覆盖是 2.0x（1.0x）/ 1.54x（1.5x），所以 1.5x 仍为 +45.0。
**1d 的正值只是"恰好站在 1.0x 成本档上方"。**

## 8. 结论

1. **12h / 1d 单尺度不为正 = dev 段毛边缘≈0 + 恒定成本地板 0.075–0.09R。**
   毛 E[R] 0.028 / 0.021 只覆盖成本的 37% / 26%，净额必然为负。
2. **成本侧没有可优化空间**：地板跨周期恒定（0.075–0.094R），慢周期的费用优势被资金费抵消
   （1d 资金费占总成本 62%–66%）。降费不是这两个周期的出路。
3. **毛利侧的两个流失口都可量化**：
   - 无目标位 ⇒ 到过 +1R 只捕获 31%–35%，dev 段回吐 69.3R（12h）/ 28.1R（1d）；
   - 止损≈0.8σ(持仓期) + 零漂移 ⇒ 42% 打满止损（理论值 44%）。
4. **根本原因是市场状态**，不是参数：dev 漂移 t ≤ 0.8 且方向分裂、波动更高；
   test 漂移 t 0.6–0.8 且三币同向、波动更低。**12h/1d 的正边缘目前只有 test 那 216 天有。**
5. **因此不应把 12h/1d 当优化目标**（与 `RESULTS.md` §7-3/§7-4 一致），
   更不应把 full 段的正值当作"已验证边缘"——其 CI 含 0，且集中在已曝光的 test 段。

## 9. 可动杠杆（都要 prereg，且本样本内无法验证）

| 杠杆 | 作用通道 | 代价 / 风险 |
|---|---|---|
| **A. 部分止盈 / +1R 保本止损** | 直接提高捕获率（当前 31%–47%），回收"过山车"的 69.3R / 28.1R | 会削掉 2h/4h 的右尾（4h test 最大单笔 +28.4R）；**必须双周期同时评估** |
| **B. 波动过滤（不开仓阈值）** | dev 年化波动 71%–85% 时不开 12h/1d | 等于用事后可见的波动做闸门，易过拟合；且会把本已很小的样本（12h dev 221 笔 / 1d dev 69 笔）再砍一刀 |
| **C. 止损按持仓期缩放** | 目前 0.72–0.82σ，抬到 1σ 可把 42% 降到约 30% | 直接改 `risk_usdt` ⇒ 改名义额 ⇒ 移动所有冻结数字，且与 `portfolio_cap_frac` 交互 |
| **D. 资金费（1d 占 62%–66% 成本）** | 只做多、或用无资金费的执行腿 | 属执行层，当前回放链不建模 |

A 是唯一能在**不新增数据**的前提下验证的（只重跑 dev，2h/4h 可作对照臂），
但它同时会动 2h/4h 的右尾 —— **若要试，应先把 `mfe_r / hold_bars` 落盘**（候选 A 指标层），
否则无法判断"削尾"削掉多少。

## 10. 明确不做的事

- 不在 dev 段给 12h/1d 调参：dev 里没有可收割的漂移，调出来的任何参数都是噪声拟合；
- 不用 test 段做任何"改进验证"（曝光 ≈20 次）；
- 不把"12h full +51.5 / 1d full +10.6"写进任何裁决：它们是 dev 0 边缘 + test 单段贡献的加权；
- 不动 D-1（容量口径）/ D-3（`campaign.py:439` whitelist 未归一）—— 两者会移动本报告全部绝对数字。

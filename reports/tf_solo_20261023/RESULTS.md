**问题**：把 a0 冻结链拆成"每个 TF 单独成链"跑一遍，看单尺度各自的净收益 / 胜率 /
PF / DD。与组合链路相比，**唯一差别是参与回放的时间尺度集合**。

**性质**：只读诊断。不改 `config/`、不改 `src/`、不产生新的裁决结论；
所有数字可由 `scripts/_diag_v21_tfsolo.py` 复现。

## 4. 组合链路 vs 单尺度：不是"尺寸差"，是"选股差"

按 `(symbol, open_ts, direction)` 逐笔配对（explore full@1.0）：

| TF | 组合 N | 单链 N | 配对 | 仅组合 | 仅单链 | risk 比(单/组) | 配对 net(组) | 配对 net(单) |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 2h | 481 | 482 | **480** | 1 | 2 | **1.000** | +71.8 | +73.0 |
| 4h | 256 | 255 | **253** | 3 | 2 | **1.000** | +172.3 | +176.5 |
| 12h | 309 | 295 | 220 | **89** | **75** | 0.800 | +21.9 | +16.3 |
| 1d | 107 | 107 | 86 | 21 | 21 | 0.833 | +9.0 | +5.0 |

配对样本内部的 **E[R] 逐位相同**（2h +0.084；4h +0.286；12h +0.015；1d +0.049）
—— 同一条交易在两条链里的 R 完全一致，差别只来自"进来的是哪一批交易"：

| 桶 | N | net | E[R] |
|---|---:|---:|---:|
| 12h 只在组合链 | 89 | −16.2 | −0.06 |
| 12h 只在单链 | 75 | **+35.2** | **+0.27** |
| 1d 只在组合链 | 21 | **+26.4** | **+0.55** |
| 1d 只在单链 | 21 | +5.6 | +0.23 |

**读法**：

- **2h / 4h 是自洽的**：交易集合 99% 重合、尺寸比 1.000、配对 E[R] 逐位一致
  ⇒ 这两个 TF 的边缘可以脱离组合链单独讨论、单独优化。
- **12h 被组合链挤掉了它最好的那 24%**：单链独有的 75 笔 E[R] **+0.27**，
  组合链独有的 89 笔 E[R] **−0.06**。所以组合链里 12h 的 `+5.7`（§6）
  不是 12h 的边缘，是"被截断后的残值"。
- **1d 反过来靠组合链"借"到交易**：只在组合链出现的 21 笔 E[R] **+0.55**
  ⇒ 1d 的 `+35.5` 里有 3/4 来自路径依赖的交易，不是 1d 自己的稳定边缘。

### 机制：真正的约束是 `portfolio_cap_frac`，不是 TF cap

单尺度回放的准入计数（full@1.0，`portfolio_cap_skips / opens_filled`）：

| TF | explore | book4 |
|---|---|---|
| 2h | 29 / 482 (6%) | 62 / 629 (10%) |
| 4h | 22 / 255 (9%) | 36 / 331 (11%) |
| **12h** | **243 / 296 (82%)** | **574 / 350**（同仓位反复重试被拒，非去重计数） |
| 1d | 36 / 108 (33%) | 129 / 130 (99%) |

`portfolio_cap_frac=0.03` 对全局风险预算封顶；2h/4h 周转快，一次仓位只占住预算很短，
12h/1d 持仓 1–7 天，**同样的预算在它们手里只能开 1 个左右的位置**。所以"12h/1d 在组合链里
表现差"首先是**预算分配问题**，其次才是信号问题。

## 6. 对上一轮 §1 结论的修正

上一轮说"12h 在 1.5x 成本下为 −21.5 ⇒ 12h 成本敏感"。**这条不成立**：

| | 组合链（共享预算） | 单尺度（独占预算） |
|---|---:|---:|
| 12h net@1.0 | +5.7 | **+51.5** |
| 12h net@1.5 | **−21.5** | **+45.0** |
| 12h E[R]@1.5 | — | +0.080 |

单独成链时 12h 在 1.5x 下仍有 +45.0 / E[R] +0.080。组合链里的 −21.5 主要由
**§4 的选股截断 + 预算挤占**造成（另加组合权益路径不同带来的尺寸差 0.80x）。
⇒ 12h 的问题不是"扛不住成本"，而是"在共享预算里拿不到它的交易"。

同理，上一轮"4h 是唯一 1.5x 仍为正的周期"应修正为：**4h 是唯一在两本书、两个成本档、
dev 与 full 上全都为正且 DD 最低的周期**（explore E[R] +0.302 / book4 +0.209 / DD 9.4%–15.3%）。

## 7. 由此得到的实验纪律（下一轮用）

1. **因子实验只在 2h / 4h 上做**：这两条链的交易集合与组合无关（99% 重合，配对 E[R] 逐位相同），
   单臂结果可以脱离账面组成解释。12h / 1d 的单臂结果会被"哪批交易进来了"污染 ——
   这正是 B2（dev +111.4 → book4 −71.4）与 A3（dev 正 / test 负，符号翻转）的机制。
2. **12h / 1d 的改动一律按"预算实验"立项，不按"因子实验"立项**：要动的是
   `portfolio_cap_frac` 的分层（给慢周期保底并发 / 按持仓时长计费），不是事件闸门；
   且必须同时报 `portfolio_cap_skips`，否则无法区分"没信号"和"没预算"。
3. **12h 的正边缘只在 test 段**（dev −71.9 / −14.1）：任何 12h 上的"改进"都默认是
   test 段过拟合，除非有 virgin 样本。
4. **1d 的 dev 符号随账本翻转**（−6.3 vs +28.4）⇒ 1d 暂不作为优化目标。

## 9. 局限

- "单尺度"= 该 TF 独占 300U 账户与全部风险预算；**不是**"同一批交易换个尺寸"。
  账户路径不同，`risk_usdt` 因此不同（12h 0.80x / 1d 0.83x）；所以 §4 用配对样本的
  **E[R]** 来隔离这一项，而不是用绝对净额。
- 本报告只做隔离回放与分解，**不构成任何臂的通过/否决**；也没有解封 test 决策。
- dev 段未做 parity（参考产物在 `closure_20261023/` 根目录，口径已注）。
- 12h 的 `portfolio_cap_skips` 在 book4 里大于 `opens_filled`，因为同一仓位在后续
  bar 会被反复重试计数；该比值只能横向粗看，不能当"拒绝率"精确读。

**12h / 1d 的负数只发生在 dev 段。** 归因见 `WHY_12H_1D.md`：

- 成本地板对四个周期恒定（0.075–0.094R）；慢周期的费用优势被资金费抵消
  （1d 资金费占总成本 62%–66%，中位持仓 132–182h）；
- dev 段毛 E[R] 仅 +0.028 / +0.021（覆盖成本 37% / 26%），test 段同参数 +0.414 / +0.281；
- 机制：无目标位 ⇒ 到过 +1R 只捕获 31%–35%、dev 段回吐 69.3R / 28.1R；
  止损≈0.8σ(持仓期) + dev 漂移 t ≤ 0.8 ⇒ 42% 打满初始止损（driftless 理论值 44%）；
- 按笔 bootstrap 95% CI 全部含 0 ⇒ full 段 12h/1d 的正值不能当"已验证边缘"。

§7 的实验纪律不变，并新增一条：**A 类（部分止盈/+1R 保本）若要做，先落盘
`mfe_r / hold_bars`**，否则无法度量它对 2h/4h 右尾的削减。

## 1. 样本分层(本轮最重要的规则变化)

20261022 轮已对 BTC/ETH/SOL 的 test 段解封 **两次**(B、D)。同一 test 段再解封
不产生确认力,只产生多重比较膨胀。因此:

- **BTC/ETH/SOL = 探索集**(已污染)。在其上得到的正结果,结论标签**上限 `WEAK`**,
  无论闸门怎么过,**都不允许**据此改 `config/v21.json`。
- **DOGEUSDT = 确认集**(virgin)。`config/v21.json` 的 `symbols` 本就含 `DOGEUSDT`,

  DOGE 上看过之后即作废,不得二次使用。

即:`WEAK` = 只能进 backlog;`CONFIRM` = 必须含 DOGE 同向。

## 3. 判定规则(先写死)

指标同 `metrics()`:`net@1.0x / net@1.5x / MaxDD / N`(仅 `closed and in_segment_open`)。

### 3.1 探索集(BTC+ETH+SOL)——四格全过 + 幅度下限

- **E1**:`net@1.0x(dev) > a0`
- **E2**:`net@1.5x(dev) > a0`
- **E3**:`net@1.0x(test) > a0`
- **E4**:`net@1.5x(test) > a0`
- **E5**(新增,防噪声):`Δnet(full@1.0x) ≥ +25 USDT` —— 约等于 test 段单点噪声
  1 SE(N_test≈346,trade-level σ 使 ±25 为常态波动),小于该值的"改善"不予采信
- **E6**:`MaxDD(full) ≤ MaxDD(a0,full) + 3.0pp`

四条(E1–E4)任一不过 ⇒ 该臂在探索集上 `REJECT`。
E1–E4 全过但 E5/E6 不过 ⇒ `WEAK(dev-only / noise)`。
**即使全过,标签仍为 `WEAK`(test 已烧,见 §1)。**

### 3.2 确认集(DOGE 全段,一次性)

- **C1**:`net@1.0x(DOGE, arm) > net@1.0x(DOGE, a0)`
- **C2**:`net@1.5x(DOGE, arm) > net@1.5x(DOGE, a0)`
- **C3**:`MaxDD(DOGE, arm) ≤ MaxDD(DOGE, a0) + 3.0pp`
- **C4**:`N(DOGE, arm) ≥ 0.5 × N(DOGE, a0)`

C1–C4 全过 ⇒ `CONFIRM(symbol-OOS)`;否则 `REJECT(DOGE)`。

### 3.3 B2 的额外约束

B2 是**记账性补跑**(执行完整性),不是新假设:
- dev 按 §3.1 的 E1/E2/E6 判(不跑 test —— 12h 缩减在 test 无增量信息);
- 无论结果,**不得**据此改配置;只登记"注册的 B 刻度下结论是什么"。

## 4. 归因诊断(不参与任何判定)

**T-split**:把 a0 中 `regime==TRANSITION` 的入场按 `_regime_from` 的具体成因拆成两类,
分别报 `n / net / 每笔 net`:

- `T-wide`:`span > 3·ATR`(宽幅)
- `T-unordered`:其余(`pivots<4` / 单边 pivots / 收盘破趋势 / `atr<=0`)

目的:回答"TRANSITION 是不是一个可交易的单元",还是只是一个**成本和噪声容器**。
拆分规则写死为上面二分类,不按结果再切。

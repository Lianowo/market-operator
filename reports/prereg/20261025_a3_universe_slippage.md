## 1. 为什么必须"先量分布"

现有 A3 的唯一数字是 **18.71 bps**,但它是**均值**;本次 16 笔可配对样本的实际分布是:

| 统计量 | 值 |
|---|---|
| 中位 | **−9.6 bps**(有利) |
| 均值 | +5.0 bps |
| p90 | **+59 bps** |
| 最差 | **+281.5 bps**(DOSUSDT) |
| >20 bps 的笔数 | 4 / 16 |

⇒ 均值被 4 笔尾部拉动。若直接按"常数 +18.7 bps"重跑,等于**给每一笔都加上尾部成本**,
会把 2h 判死;而按分布重跑(大部分笔有利、少数笔极差)可能得出相反结论。
两种口径对 2h 的判定方向相反 —— 所以本轮的第一产出是**口径**,不是结论。

另一个已知的量级锚:2h 名义/风险 **55×** ⇒ 1 bp = 0.055% 名义 = **0.0055R/边**,
`10 bps` ≈ 0.055R/边、往返 0.11R;`18.7 bps` ≈ 0.10R/边、往返 **0.21R**;
2h 的基线 `E[R]` 是 **+0.082**。**成本口径的 1~2 bps 误差就能翻转 2h 的结论。**

## 3. 臂定义(一臂一变量)

### M0 — 基线复现(必须逐位一致)

`a0` + 常数滑点 `3.33 bps` + `funding_source=hist`(A1 口径)。
产出 `full@1.0x` 必须 = `+594.45`;不等则本轮作废(说明基线已漂)。

### M1 — 逐标的实测滑点(`slippage_by_symbol`,插缝已就位)

- 表来自 P0 的聚合结果:**每标的的 `slip_bps` 分布**按 `n` 抽出经验分布
  (有放回,seed 固定),成交时按方向取**逆向为正**的符号。
- 未覆盖标的:全局分布 × `(该标的 notional/risk ÷ 全局中位)` 缩放,标 `imputed`。
- **一臂一变量**:除滑点表外,其余与 M0 完全相同(同一交易集检查:若 `N` 变化
  > 2%,按"成本改变复利路径"处理,报同集反事实 `net(m)=gross−m·cost` 对照)。

### M2 — 统一尾部压力(不产生交易,只做排序)

- M0 的交易集与毛利不动,只把成本项换成 `+59 bps`(p90)与 `+281 bps`(最差)两档,
  报每 TF 的 `E[R]` 与**归零顺序**。这是稳健性检验,不作为选参依据。

## 4. 判定规则(先写死)

指标沿用 `metrics()`:`net@1.0x / net@1.5x / MaxDD / N / per-TF E[R] / cost_r`;
样本仅 `closed and in_segment_open`;成本口径 = A1(真实资金费)。

- **A1** `M0` 复现 `full@1.0x = +594.45` 且 dev/test 逐项一致
- **A2** `M1` 的 2h `E[R] > 0`(同集口径)
- **A3** `M1` 的 2h `net@1.0x$ > 0` 且 `N ≥ 80% × M0(2h N)`
- **A4** `M1` 的其余三周期 `E[R]` 相对 M0 的下降 ≤ 0.05R(隔离性)
- **A5** `M2@+59bps` 下 4h/12h/1d 至少两周期 `E[R] > 0`,且 2h 最先归零
- **A6** `MaxDD(M1) ≤ MaxDD(M0) + 3.0pp`
- **A7 尾部保护**:`M1` 的 2h 前 3 笔净额合计 ≥ M0 的 90%(§10:前 5% 交易贡献 57.3% 净额)

判定:

- **A2 通过** ⇒ 2h 可在动态宇宙继续,**D1 解除阻塞**,但 D1 立项门仍按其自身功率要求
  (Δ≈0.2R / `WEAK`)执行。
- **A2 不过而 A5 显示"4h/12h/1d 在 +59 bps 下仍为正"** ⇒ 结论为
  **"2h 只能在 BTC/ETH/SOL/DOGE 池"**,写进 `config` 前须再登记一个纯配置臂。
- **A2 不过且 A5 显示 4h/12h/1d 也归零** ⇒ 结论是**宇宙整体不可交易**,
  优先级高于任何几何调参 —— 直接回到 §9 的"少做/停做"讨论。

## 5. 反噪声细则

- M1 的经验分布**只抽一次**,seed 写进报告;不得按结果换 seed 或换分位。
- M1 与 M2 **同一批产出**(一次命令跑完),不允许"看完 M1 再决定 M2 的口径"。
- 报告必须同时给出:`per-symbol n`(含 `imputed` 标记)、`entry_settle_miss` 占比、
  每 TF 的 `N / E[R] / net$ / cost_r`、`MaxDD`、`portfolio_cap_skips`。缺任一项 ⇒ 判定无效。
- 16 笔配对样本**不足以**支撑任何 per-symbol 结论;本轮只允许产出"全局分布 + 缺失标的兜底",
  per-symbol 表在 `n ≥ 30` 之前**不得**进 `config`。

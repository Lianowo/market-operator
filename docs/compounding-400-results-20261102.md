## Limitations and outstanding work

- Canonical production strategy/risk replay, not a live-runner simulation.
- Fixed four-symbol universe, not the live dynamically selected universe.
- Campaigns have per-symbol/timeframe positions; live execution has additional
  symbol-level position constraints. No tick-level bid/ask, API failures or outages.
- Daily loss breaker and order-rate limits are not simulated. Hence the replay
  does not establish live trading parity or predict future account value.
- Equity sampled on replay execution grid; intrabar/tick drawdowns may be worse.
- No liquidation events in these runs is not proof against real liquidation.
- Current code has not passed complete production return-floor acceptance;
  risk settings need review given test/pressure drawdowns above 60%.

Source/config hashes and scenario summary metrics are preserved below. Raw trade/equity/capacity CSV files and configuration snapshots were removed after documentation checks. The formal configuration was not changed.

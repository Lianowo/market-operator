## 1. v2 候选机制 E7 FLIP_RETEST（定义冻结）

- **触发**:bar t 收盘时，某 zone 状态转为 FLIPPED（语义：破位→回踩→被拒绝→角色互换，控制权易手已确认；FLIPPED 转移本身即事件）。
- **方向**:role_new=resistance（旧支撑破位）⇒ short;role_new=support ⇒ long（对称测，不做方向挑选）。
- **入场**:open(t+1)。
- **失效价**:short ⇒ zone.hi + k_bm·atr(t);long ⇒ zone.lo − k_bm·atr(t)。
- **F1 失效距离下限**:dist(close(t), invalid) ≥ k_is·atr(t),**先验 k_is = 0.8**。
  （依据：一个不足一次 ATR 撤退的距离在 1h 尺度上是噪声；与归因观察到的 0.4%≈0.8·ATR 一致声明在先。敏感性报告 {0.6, 1.0}，不做择优。)
- **room**:目标存在且 r_mult ≥ r_min（同 §7)。
- **出场**:§8 六条原样；每 symbol 一仓；风险/成本模型不变。
- **E7 与 v1 白名单关系**:v2 回测白名单 = {E7}。E6-as-entry 被归因否定退役；E1 样本不足事后再议（不允许在同一轮加回）。

- H2:F1 下限移除 C1 桶后，净期望改善的主部来自尾部消除而非胜率提升。

# v4 研究协议（冻结于任何 v4 运行之前，2026-10-19)

> 动因：三轮证伪 + 逐笔归因 + 使用者裁决共识——亏损主源是**早产交易**（信号尚未成熟时入场，
> 紧止损只是其症状，加宽止损救不了）。v4 不再加价格条件，改为**成熟度优先**的入场与执行重构。
> 价格语义（认知/事件 E1-E7）一字不改。

## 1. v4 变更的唯一内容

**入场三闸门（入场时刻已知的客观量，全部满足才允许，否则 FLAT):**

- **G1 事件成熟度**：只有"已确认"事件可交易 ⇒ 白名单 = {E7|short, E7|long}
  (FLIP_RETEST：破位→回踩→被拒绝→角色互换完成）。破位当下入场（E6-as-entry）永久退役。
- **G2 失效位自然距离**:dist(invalid) ≥ k_is·ATR，先验 k_is = 0.8（沿用 v2 冻结先验，不重新选择）。
  距离不足 = 信号未成熟 = 无交易；禁止加宽止损、禁止补仓、禁止降格。
- **G3 限价接回踩**:E7 触发后不追价，改为在**翻转区域前缘**挂限价单
  (short ⇒ zone.lo,long ⇒ zone.hi——偏向成交率的方向，价格观感较差，如实声明），
  等待 ≤ N_fill 根 1h bar,**先验 N_fill = 12**; 超时未成交 ⇒ 撤单，**没有这笔交易**。
  记录成交率与过期率。每 flip episode 至多挂一单。

**执行路径细化（不改变语义，只改变成交真实性）:**
- 认知与决策仍走 1h；订单产生后，成交判定走 **15m 真实数据路径**（拉取同区间 15m OHLCV,
  对齐断言）——用于限价成交判定与持仓期 stop/target/退出的先后顺序解决（替代 1h 的最坏 tie-break)。
- 保守限价成交规则：仅当 15m bar **严格穿过**限价（sell limit L:bar.high > L;buy limit L:bar.low < L)
  才算成交；持平不成交（不假设排队靠前，声明残余乐观风险）。
- 费用非对称：限价入场/限价减仓 = maker 0.02%；退出（破位/CHoCH/时间）= taker 0.06% + 滑点 0.02%；
  资金费不变。目标减仓改为限价（挂对侧区域前缘，成交规则同上，等待 ≤ N_fill 否则转市价）。
- §8 持仓管理其余规则、风险预算、杠杆上限、MIN_SIZE 规则一律不动。

**信号拥挤**:E7-only 白名单后拥挤病自然缓解（E6 已退役）;E1 不加入本轮（其追价语义与 G3 冲突，
后续若有资格再单独立项）。

## 2. 样本量与统计效力声明（先于运行）

三闸门预期把 2 年 3 品种的交易数降至**数十笔量级**。因此：
- 若 test 段成交 < 60 笔 ⇒ 判 INSUFFICIENT_DATA，**不产生任何"看起来转正"的叙述**；
  低频风格的合规补证手段只有前向 paper 积累，不是修回测曲线。
- 所有 CI 如实报告，宽就宽；宁可无结论，不可窄口径。
- 即使本轮全负，也多贡献一个事实（adverse selection 与成熟度的实测），终局同样如实记录。

## 3. 评估（与历来判据同构）

- 一次性运行：dev/test（同一拐点）× 成本 1x/1.5x/2x 全成本回测；核心对比对象是 **v2 同白名单回测**
  (= 只换入场执行与成熟度闸门的 A/B)。
- 升级线不变：test 段成交 ≥60 且净期望 > 0 且 2x 成本 PF > 1 ⇒ 才可讨论 paper；否则维持 Research Only。
- test 段评估计数：第 6 次（v1×3 + v2 + v3,v4 仅一次，research-log #9）。

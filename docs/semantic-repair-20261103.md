# 语义修复（2026-11-03）：把"仓位/预算/主张"的定义改对

## 0. 验收标准

本轮**不以"回放比上一版好"为验收标准**，而以"语义是否被正确修正、且能被测试证伪"为准。
回放只作为**后果测量**：如果语义对了但回放变差，再去查是哪一个新语义在什么环境下
产生了什么代价，而不是回滚语义。

改动全部在本地工作树，未提交、未部署、未下单。配置、风险档位、容量比例、费用未改。

## 1. 已实现的四项契约

### C1 风险资本 = 已落袋现金（上一轮已落地，本轮沿用）

- **断言**：浮盈能支撑保证金（偿付能力），但不是"亏得起多少"的本金。
- **代码**：`Broker.risk_capital()`；`qty_for_entry(capital, …, notional_equity=…)`。
- **测试**：`tests/test_risk_capital.py`（5 条）。

### C2 预算主体 = 市场判断；账户是唯一预算主体

- **断言**：
  1. 同一 `标的×方向` 的全部在仓（跨 2h/4h/12h/1d）是**同一个判断**，共用一份预算；
     周期只是观察尺度，不是四个账户。
  2. 账户上限在所有时点生效（准入 + 成交），周期池不能再相加成新的总额度。
- **代码**：
  - `Broker.claim_headroom(symbol, direction, capital)`：按 `symbol_root + direction`
    汇总最坏损失，额度 = 该主张所属周期的比例 × 风险资本。
  - `qty_within_risk_budget(..., direction)`、`qty_for_entry(..., direction)`：成交侧同口径。
  - `campaign._submit_decisions`：新增 `CLAIM_CAP` 整笔跳过。
  - `capacity.RiskBudget.pools`：`admission_full_cost` 决策时刻不再丢弃账户池。
- **测试**：`tests/test_claim_semantics.py::test_timeframes_share_one_claim_budget`、
  `tests/test_capacity.py::test_admission_mode_includes_account_pool_at_decision`。
- **可证伪**：若同标的同向的跨周期仓位仍各自占用预算，这条就没实现；
  实测回放里 `CLAIM_CAP` 的触发次数见 `cap_skips.csv`。

### C3 相反主张不能同时成立

- **断言**：对同一标的，"会涨"和"会跌"不可能同时为真。两张相反仓位净敞口为零，
  却各付一份成本、各占一份预算、各等一个止损——那不是两个判断，是一个没有方向的
  账户在付费。新主张与在仓主张相反时，必须先了结旧的才允许新的；本轮实现为
  **拒绝后来者并写明原因**（反手平仓属于策略选择，未实现）。
- **代码**：`Broker.opposite_claim_open()`；`_fill_open` / `_fill_open_limit` 返回
  `SKIP(OPPOSITE_CLAIM)`；决策门同样先拦，避免武装一张注定不能成交的挂单。
- **测试**：`test_opposite_claim_is_refused_with_reason`。
- **可证伪**：若回放里仍出现同一标的相反方向的并存时段，这条没实现
  （可用落盘快照按 `symbol_root` 检查）。

### C4 主张生命周期：完成是事实，重定基要"接受"（按归因修正）

- **断言**：REJECT 的主张是"这次边界拒绝会把价格送到对侧"。
  - **到达对侧（触价）= 完成事实**，记入 `claim_completed_ts`，但**不改防线**；
  - **收盘越过目标 = 接受**，此时才把风险基准换成峰值锚定的回吐预算（由
    `opp_lock_step` 的 arming 条件承担）；
  - 若同根出现同向"外侧接受"（`BREAKOUT_ACCEPTED`），换签为**迁移主张**
    （target 清空，交给移动防线）。
- **为什么改成这样**：单变量归因显示"触价即重定基"是唯一同时伤害收益与回撤的语义
  （关掉它：净 +19.4k、回撤 −12pp）。触价时峰值≈目标，防线立刻抬到
  `entry+0.25×span`，任何 75% 回撤就出场——剪掉了趋势右尾。
  **到达 ≠ 接受**；一次插针不应该改掉整段行程的持有权。
- **代码**：`Position.claim_completed_ts / claim_migrated_ts`；
  `PositionManager.on_bar` §2.5；实盘 `live_runner._on_sub_bar` 同口径。
- **测试**：`test_claim_completion_is_recorded_but_does_not_rebase_risk`、
  `test_acceptance_beyond_target_arms_the_giveback_budget`、
  `test_completed_claim_with_same_direction_acceptance_is_re_underwritten`。
- **可证伪**：若出现"未接受（无收盘越过）却被重定基"的仓位，这条实现错了。

## 2. 尚未实现、且不应悄悄塞进去的两项

### C5 证伪价必须属于同一几何版本

箱体退役/重建不自动取消合法突破主张，但旧主张的止损不能引用新几何的价位。
这需要 `box_id + geometry_version` 贯穿 `structure → events → routing → position`。
它是身份系统的重写，不是一处判断；在没有把"边界微移"和"换箱"区分开之前动它，
只会制造第二套不一致。**本轮明确不做**，原因写在 `docs/balance-semantics-20261103.md` §4。

### C6 主张的有效期（观察尺度）

12h/1d 的诊断显示：止损距离（4.2%/7.5%）小于持有期要穿越的振幅（3 月 17%–27%），
且持有期内漂移与盈亏相关性 0.98–0.99。这说明"主张缺少有效期"。
但"有效期 = N 根 bar"必然引入一个数字；没有独立证据前，它只能是调参，
不是语义修正。**本轮不做**，只把它作为下一个需要显式定义与单独回放的契约。

## 3. 与"门槛/过滤/参数"的边界

- 未新增任何数值阈值；`risk_frac`、档位、12%/50%、`frac=-0.25` 全部未改。
- 改的是四个定义：**什么算本金、什么算一份预算、什么算一张仓位、主张何时结束**。
- 两处旧测试被改写，因为它们断言的正是被修正的旧语义：
  - `test_admission_mode_checks_only_timeframe_pool_at_decision`
    → `test_admission_mode_includes_account_pool_at_decision`（账户池必须在场）；
  - `test_v21_per_tf_capacity_…` 中"触价不 arming、等收盘越过"的断言
    → "触价即完成、风险重定基"（并保留原 105.0 那条路径的其余断言）。

## 4. 回放后果（测量，不是验收）

同入口、同 250U、同行情、同配置，唯一差别是本轮语义。

| 场景 | 净收益 | 最大回撤 |
|---|---:|---:|
| 冻结基线 | 24,844.9 | 51.63% |
| 仅 C1（风险资本） | 29,650.2 | 44.57% |
| **C1–C4 全部** | **14,343.9** | **49.08%** |

**变差了，而且不是小幅。** 按约定不回滚语义，先查清代价来自哪里。

### 4.1 代价归因

| 事实 | 数值 |
|---|---|
| 已闭合（报告口径） | 646 → 528 |
| 段内开仓且闭合 | 608 → 492 |
| 每笔平均 R | 0.270 → **0.305** |
| 每笔 R 中位数 | −0.314 → **−0.093** |
| 总风险投放（Σrisk ÷ 初始资金） | 380× → **195×** |
| 被移除的 137 笔（基线口径） | 合计 **−2,266U（本来就是亏的）** |
| 新增的 20 笔 | 合计 −858U |
| 同一批 472 笔中出场方式改变 | 34 笔（30 笔 保护止损→v21），净 −511U |

**结论：净收益减半的主因不是"砍掉了好交易"，而是"风险投放减半"。**
被语义规则移除的交易在基线里是净亏的；保留下来的同一批交易，每单位风险的表现
略差（0.368R → 0.339R），但整体 meanR/medianR 反而改善（因为亏损单被剔除）。

### 4.2 为什么回撤百分比几乎没降

| 窗口 | 基线 DD | 修复后 DD |
|---|---:|---:|
| 2024-10 → 2025-11 | 38.36% | 34.33% |
| 2025-11 → 2026-02 | 40.62% | **49.08%** |
| 2026-02 → 2026-05（原目标窗口） | 51.63% | **47.25%** |
| 2026-05 → 2026-10 | 42.69% | 43.56% |

- 目标窗口从 51.63% 降到 47.25%，**方向是对的**；
- 但 2025-11→2026-02 段恶化，成为新的最大回撤；
- 更根本的是：**百分比回撤对按比例缩仓不敏感**。风险减半时，盈利与亏损同时减半，
  `峰值/谷底` 的比值几乎不变。所以"修语义"能改变绝对生存（最低权益、恢复时间），
  但**不能靠缩仓把百分比回撤修好** —— 那需要改变负优势期的暴露或提高每笔优势。

### 4.3 不变量核验（回放产物）

- 同一标的同时持有相反方向：基线 122 笔 → **0 笔**（C3 生效）。
- 容量拒绝分布：`OPPOSITE_CLAIM` 144、`CLAIM_CAP` 34、`TF_CAP` 42、`PORTFOLIO_CAP` 3。
- 出场原因：`v21`（回吐预算）62 → 83，说明"完成即重定基"确实接管了一部分仓位。
- 仍然存在 171 笔"同向跨周期并存"：这是**预算内**的（12% 额度可容纳约 3–4 条 3% 的腿）。
  把"同一主张只能一张票"做实，需要几何身份（C5），本轮未做。

## 5. 下一步的问题（由本轮暴露）

1. **百分比回撤不是仓位问题。** 原目标窗口只从 51.63% 降到 47.25%，同时另一段升到
   49.08%。需要的是"负优势期少暴露"，即 C6（主张有效期），而不是继续缩仓。
2. **绝对收益依赖风险投放倍数。** 修正后从 380× 降到 195×，收益随之减半。
   要把收益拿回来，只能提高每单位风险的产出，不能把杠杆加回去。
3. **"一主张一票"仍未成立。** 预算共享已经生效，但同一标的同向仍可容 3–4 条腿；
   要做到一票，必须先有 `box_id + geometry_version`，否则无法判断两条腿是否同一主张。

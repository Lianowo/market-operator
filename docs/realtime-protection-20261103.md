# 实时价格保护时钟（2026-11-03）

生产变更只有一条：**目标锁利的价格时钟从 2H 子 bar 改为 15m 收盘 arming + 5s 报价棘轮**。

- 不再等 2H 才计算/设置目标锁利；
- 15m 收盘越过目标 → arming；
- 之后每 5s 用新鲜 `lastPr`/`markPrice` 推进峰值和防线；
- `invalid` 变化后先挂新 TPSL、拿到 orderId 再撤旧单；
- 固定止损仍由交易所原生 TPSL 兜底。

## 配置

```json
// config/live.json
"loop": {"poll_seconds": 5},
"protection": {
  "price_clock": "15m",
  "max_quote_age_seconds": 30
}
```

`config/strategy.json` 不变：`reject_opp_lock_frac=-0.25`，`n_a=3`。

读法：

- 净额下降约 **11%–12%**；
- “目标到过又净亏”在 dev/test/full 三段都下降（full 28/31→19/24）；
- 1.5x DD 在 test/full 改善，dev 变差；1x DD 略变差；
- 交易数略增（full 586→596）。

这是**风险/收益交换**，不是收益优化承诺。它直接解决 IDOL 类“目标到了但 2H 后才锁”的问题，代价是净额下降。

## 边界

- 回放是 15m OHLC；实盘用 5s 报价棘轮，采样间极值仍可能漏，交易所 TPSL 是固定止损后备。
- `price_source=="ref"` 的仓位先保留固定保护，等 `_reconcile` 回写交易所 VWAP 后再进入锁利。
- 15m 收盘是 arming 来源；报价不会自行授予资格。
- test 段已被多轮研究使用，不是新的独立样本外。

## 四、仍待修复的语义边界（不在本轮批量改动）

### 1. 机会身份不能由价格近似或 Python 对象地址替代

TrueBalanceBox / BracketLevel 已有 box_id，但 Zone 未携带它。
桥接按同角色近邻价格复用对象，可能把不同箱或 FLIPPED/BOX 来源接成同一对象；
路由离带重置却按取整边界价格建键，边界微移又会被当成新机会。
同一试探可能被拆为新机会，不同试探又可能共享旧证据。

建议契约：稳定的 box/edge/auction identity 与 geometry version 分离；
纯属性刷新不重置证据，真实边界/来源变化不能偷渡旧证据。
ACCEPT 候选需绑定其证明过的边界快照，不能用旧 ref 与新 zone 混拼。
**夹板切换或箱体突破退役不自动使旧候选无效**，否则会破坏合法的突破确认。

### 2. 边界拒绝、箱内轮动、箱外迁移是不同主张

REJECT 只证明这次边界试探回收，不自动证明整箱穿越。
ACCEPT 的连续外侧收盘证明外侧驻留，不自动证明可持续迁移。
不能靠多等 N 根或更大冲量把事实名字升级为更强的预测。

建议每笔假设显式携带：来源与版本、已知证据、交易主张、结构证伪、
机会完成、继续持有许可。箱内行程完成后，若继续持有，必须说明新的迁移事实
是什么，而不是自动继承趋势仓语义。反过来，回到旧价值区使箱外主张被证伪时，
应由原认知周期裁决，不能只等与该主张无关的宽 ATR 风险线。

这里“完成后结束”与“有证据继续迁移”是需要分别回放的合同候选，不是已证实
优于现规则的止盈方案。不强制加小周期惊吓退出，不恢复庞大的退役 STCE 状态机。

### 3. 相同原语的两层实现与回放分支要一致

认知层具备 R3 失败突破回收，触发层破位即移除 episode 且无对应 outside_closes
证据，存在覆盖不一致。应共享语义事实，不能仅共享事件名。
默认粗执行路径还存在限价入场当根保护复查与 fine_execution 分支不一致的缺口；
它属于回放正确性，不能当成市场优势修复。两项均尚未在本轮实现或验收。

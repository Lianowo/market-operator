## R1 · 剩余行程 / 赔率结构

### 1. 先把"赔率"量出来（planned RR = |target−entry| / |entry−invalid|）

回撤窗口内（n=84）：

| planned RR | 笔数 | 胜率 | 平均 R |
|---|---:|---:|---:|
| <0.5 | 18 | **66.7%** | **+0.153** |
| 0.5–1 | 15 | 33.3% | −0.335 |
| 1–1.5 | 2 | 0% | −0.378 |
| 1.5–2.5 | 31 | 22.6% | −0.176 |
| ≥2.5 | 18 | 22.2% | −0.077 |

回撤窗口外（n=376）：

| planned RR | 笔数 | 胜率 | 平均 R |
|---|---:|---:|---:|
| <0.5 | 96 | 62.5% | +0.129 |
| 0.5–1 | 126 | 53.2% | +0.198 |
| 1.5–2.5 | 96 | 33.3% | **+0.514** |
| ≥2.5 | 54 | 33.3% | **+0.859** |

**同一个变量在两个环境里符号相反**：期外"目标远"是优势（+0.86R），期内"目标远"是劣势（−0.08R）。
所以 **赔率不能当规则**：任何"要求 RR ≥ x"的约束都会在一个环境里赚钱、在另一个环境里亏钱，
而这正是"参数"的定义。

### 2. 赔率为什么会长成这样：它其实是"位移赌注"

各周期入场几何（中位数，ATR 计）：

| 周期 | planned RR | 目标距离 | 入场离箱沿 |
|---|---:|---:|---:|
| 2h | 0.71 | 1.71 | 2.13 |
| 4h | 0.83 | 2.42 | 2.86 |
| 12h | 1.87 | **7.26** | 3.36 |
| 1d | 1.72 | **8.89** | 4.45 |

- 12h/1d 的目标在 **7–9 个 ATR** 之外——那是"月度级别位移"的价格距离。
- 入场点已经在箱沿外 **3.4–4.5 个 ATR**：拒绝动作在成交前已经走了一段。
- 证伪距离 3.4–4.5 ATR，目标 7–9 ATR：**这不是"赔率不合理"，而是"要的东西太大"**。
  在有位移的行情里它给 +0.86R；在没有位移的 3.5 个月里，价格先碰到 4.45 ATR 的证伪。

### 3. 结论（负结果）

- **不新增任何 RR / 剩余行程约束**。数据显示它符号翻转，加进去就是调参。
- "入场时剩余行程"没有可用的区分力：期内外入场离箱沿距离几乎相同（2.83 vs 2.71 ATR），
  说明它不是回撤的原因，也不能预测结果。
- 真正决定成败的是**位移是否存在**，而它在入场时不可知：回撤窗口内四个 regime 桶全亏
  （TREND_UP 23%、TREND_DOWN 29%、TRANSITION 36%、RANGE 33%），标签无区分力。
- 因此 R1 的正确结论是：**停止在赔率几何上找解**。若要继续，只能研究"已实现的位移"
  （例如箱体是否已被完整穿越过），那属于结构事实，不是入场时的预测。

## R5 · 跨标的同摆动

### 1. 量测（14,729 个有仓小时）

| 指标 | 值 |
|---|---:|
| 总止损风险 / 现金：中位 | 8.4% |
| 同上：p90 | 20.7% |
| 同上：最大 | **119.3%**（2026-08-19 22:00，5 条腿） |
| 主导方向风险 / 现金：中位 | 7.2% |
| 同上：p90 | 18.6% |
| 同向占比 >12% 的小时 | **25.2%** |
| 总风险 >24% 的小时 | 6.5% |
| 同时持有多空的小时 | 30.7% |
| 跨标的 6 小时内同时止损的簇 | 115 |
| 其中**同向**簇 | 64（149 笔） |
| 同向簇合计净收益 | **+1,984.2U** |
| 最差同向簇 | −1,182.5（5 空）、−885.2（2 多）、−830.4（3 多） |

### 2. 两个反直觉结论

1. **"同向多标的"本身不是错误来源**：64 个同向止损簇合计 **+1,984U**（净正）。
   按方向或相关性去设"一次摆动只给一份预算"，会同时砍掉赚钱的那部分。
   所以 R5 不能做成"方向/相关性过滤器"。
2. **真正的问题是预算被当成"流量"而不是"存量"**：总风险最多到现金的 **119%**。
   成因可核对：那 5 条腿是在权益更高时按**盯市权益**下的注，之后现金没有跟上
   （浮盈未落袋），于是"风险/现金"被放大。C1（风险资本=现金）与 C2（账户池在所有时点参与）
   已经把入口堵住，但**已有仓位不会因现金下降而收缩**——预算只在准入时被检查。

### 3. 结论与下一步

- **不做**：方向相关性预算、同摆动合并、按 symbol 的风险上限（都会砍掉正收益簇）。
- **要做（待测）**：把预算从"准入闸门"变成"存量约束"——每根认知 bar 复核
  `Σ最坏损失 ≤ 预算`。若持续超限，必须显式选择处置（减哪一条腿），这是策略决策，
  不是语义事实；因此**先用新语义重测超限频率**，再决定是否引入。
- 这项测量的前提：新语义下的回放要保存逐时逐仓快照（当前 CLI 不保存），
  否则无法判断 C1/C2 是否已经把 119% 这类情况消掉。

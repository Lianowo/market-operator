# 边沿早入场固定协议（2026-11-02）

目标：2h只提供已知边沿，不等待2h ACCEPT/REJECT许可，比较30m二次测试失败与扫出收回。

## 冻结规则

- 最近在30m开盘之前已收盘的2h结构提供ACTIVE BOX_EDGE、ATR、对侧内沿和趋势；不使用当根尚未收盘2h。边沿进入观察后冻结。
- 前30m收盘在箱内一侧，本30m高低区间进入边沿，开启观察。仅活动原始箱沿，不使用翻转沿。
- 二次测试：第一次极值后，不创新极值的一根后续30m收盘越过首次极值所在K线的反向端点，登记回弹；之后另一根30m再测边沿且不创新极值，冻结两次测试之间的反向极值；再之后30m收盘突破该价位才触发。多空镜像。同根不推测先后。
- 扫出收回：30m刺穿外沿0.1个2h ATR且收回内沿；冻结该K线反向端点。之后30m收盘越过端点才触发；先创新测试极值则取消。
- 止损：本轮测试极值外0.1个冻结2h ATR。目标：冻结对侧内沿。只允许距离内沿向箱内不超过0.5个2h ATR，剩余RR>=1.5，往返名义成本0.0016×价格/风险<=0.25。
- 观察最长12小时；目标已过、上层边沿身份消失取消。身份按角色与origin_known，不追随边界小幅更新。
- 触发/拒绝后锁定。整根30m回箱内、离内沿至少0.3个当前2h ATR后复位，下一根才可新测。
- 每次观察仅一次机会；容量或仓位忙也消耗该信号，不补追。组合组为两个独立状态机信号并集，同收盘先二次测试、再扫出收回，每个战役最多提交一笔。
- 收盘确认后下一15m开盘市价执行。开盘滑点/跳空后仍由broker检查目标和RR。不存在盘中止损入场订单或同根回填。
- 替换2h REJECT入口，原2h ACCEPT及4h/12h/1d保留。初始止损为测试极值，后续2h持仓管理不变，不加30m移动止损。
- 五臂：baseline、accept_only（删除2h REJECT消融）、double_test、sweep_reclaim、combined。各dev/test/full × 1x/1.5x，共30场景。
- 300U、0.75%权益风险、正式容量与历史资金费，四币，所有组15m撮合。沿用现有历史数据，不抓新数据、不改实盘。

## 验收与局限

报告组合及2h净收益、回撤、币种集中度、剔除最大5笔收益；新入场的边沿距离与从首次测试起等待。
噪音代理为2h已平仓交易净亏且入场后保守最大有利位移不足0.5R的比例。退出15m只取退出价，不借用退出后极值。
新旧机会集不同，距离/等待不宣称同一笔提前。未获得逐笔成交，OHLC内先后仍有近似；不承诺零噪音。
历史test被多次使用，不能称全新独立样本外。无参数搜索；如果收益改善但噪音代理明显恶化，不宣称目标达成。

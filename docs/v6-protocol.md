## 1. 战役引擎（基础设施，非策略变更）

- 认知尺度 TF ∈ {1h, 2h, 4h, 12h, 1d}；由既有 1h 带哈希数据 UTC 对齐聚合（已实现入 manifest)。
- **战役隔离**：每 (symbol, TF) 一对为独立战役：自有结构认知/事件/策略状态/持仓/挂单，
  互不感知；跨战役共享的仅账户权益与组合风控。
- 决策在 TF bar 收盘；成交/持仓路径解决：TF=1h 用既有 15m 路径，TF≥2h 用 1h 路径（对齐断言）。
- 组合约束（冻结先验）：单战役风险 risk_frac 不变；**全部战役合计 open 最坏情景 ≤ 3% 权益**,
  超出按信号时间 FIFO 跳过并记 reason；每战役同时一仓一挂单；强平保护沿用。

## 2. 语义修复（唯一策略变更，两项）

### S1 失效锚定结构区边界（替代微观极值）
E1/E6/E7 全部入口的 invalid 统一改为**setup 区域的边界外 ± k_bm·atr**——short ⇒ flip/破位区
hi + buf；此天然含区域宽度缩放（ZOB/Turtle 共识）。F1(≥0.8·atr）保留为**闸**而非修补：
天然距离不足即笔不存在，禁止人工加宽。

### S2 出口几何：Target-Clamp（主臂 A)
- target_1 = **2.0R**（以实际失效距离计）；若对侧结构空间 < 1.5R ⇒ 无交易（沿用 room/r_min)。
- 触 target_1 减仓 50%；余仓**只准 pivot 移动防线，禁止移保本**(ZOB 反模式实证禁令）。
- §8.1 破位出、§8.5 反向 CHoCH、§8.6 时间止损不变；加仓仍关闭。
- **dev 对照臂 B（判一选一）**:Turtle 式——无固定目标，初始 invalid=2.0·atr，确认 pivot 后
  trailing=min（现防线， pivot±buf)，仅 §8.1/§8.5 出场，关时间止损；A/B 只许在 dev 比较，
  test 只许跑获胜臂一次（臂选择规则：dev@1.5x 净期望较大者；若两者皆负，取显著性更不差者并声明）。

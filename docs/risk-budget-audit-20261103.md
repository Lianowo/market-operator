- 同方向容量的**执行能力**与预算的**具体数值**是两项交付。补齐闸门不等于必须选择 6%，更不等于必须连同其他参数一起切 J 档。

- **撤回“J 档已完成收益/风险验收”“27% 是回撤下限”的结论。** 新证据既不支持直接认定 J 最优，也不支持把旧 5% 风险档原样作为新 15m 链路的默认安全预算。
- 15m 保护、条件快速 ACCEPT、风险参数必须分别归因。此次只固定前两者、比较预算，不证明它们相对旧生产链的独立收益贡献。
- 缩仓不能改变一个固定交易假设的单位风险期望；容量门会改变成交集合，既会拦亏损，也可能拦盈利。不能把风险下降记作发现震荡 alpha。

## 4. 收益为何下降

1. **仓量直接下降。** 同权益、同止损距离、尚未受杠杆/最小量限制时，单笔从 5% 到 1.5% 对应风险目标仓量变为 30%。实际动态风险按权益匹配档位，因此整段金额不会简单等比例缩放。
2. **复利路径改变。** 小仓盈利带来的后续可下注权益更低，连续盈利时全段利润差距可以远大于单笔风险比；更小仓也能减轻连续亏损，因此不能假定风险越高收益必然越高（例如 test 1.5x 的 C 净增高于 A）。
3. **容量闸门改变交易集合。** C → D → J 并非只改变同一批交易的数量，而是改变哪些交易可成交。J 的 test 1x 有 73 次同方向容量拒绝，full 有 178 次；这些是拒绝次数，不是独立交易数。
4. **6% 不能孤立配旧 5% 单笔。** 单笔 5% 接近整个同方向 6% 预算；第一笔后剩余空间很小，成本又占用预算。B 的 test/full 平仓数均明显减少，且 test 1.5x 已负收益，不能视为“保留旧收益、只挡超额相关风险”的免费改动。
5. A → J 的 test 1x 净增下降 82.94%，full 下降 94.54%；这是本样本的盯市利润比较，不是未来收益预测。C → J 的 test 1x 净增下降 69.01%，DD 却从 36.56% 到 36.80%；full DD 几乎相同（36.31% 与 36.28%）。在 1.5x full 上 J 比 C 的 DD 更低（40.70% 与 43.91%），故也不能据此断言容量门普遍无效。

**研究结论：撤回“6% + 完整 J 档已验收”的判断。预算选型应由可接受回撤与收益代价共同决定，不通过再次缩仓宣告震荡研究完成；不能因为 C 在此样本表现好就直接上线。本分支按用户要求不保留风险实验实现，恢复基线并不构成对旧预算安全性的证明。**

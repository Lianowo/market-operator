## 研究过什么

历史 A 为首档单笔 5%、组合 50%、每周期 12%、无同方向上限；J 为 1.5% / 12% / 4% / 同方向 6%；I 为 2% / 15% / 5% / 同方向 8%。这不是只调整一个参数，而是同时改变下注量和允许成交的交易集合。

旧表曾记录 J test/full DD 27.81% / 27.34%，但：

1. 旧脚本没有显式传入 15m 执行网格，默认实际为 1h。
2. 风险阶梯从当前 live 配置读取再乘系数；配置改变后重跑会二次缩风险。
3. 旧产物未完整冻结参数，不能仅凭变体名称复现。

所以旧数字不再作为部署验收值，也不能推导最优档位或回撤下限。

250U、趋势第一根快速 ACCEPT、普通三根确认、显式 15m、1x 成本；净增为期末盯市权益减 250U。

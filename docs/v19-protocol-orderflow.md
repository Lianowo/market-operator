# 订单流历史回放研究协议（冻结，2026-10-21)——aggTrades 接触点检验

> 本协议只做**测量**（tape 特征在接触点是否有增量信息）,v12(K线轻量）已死；
> 本次接触**真逐笔**(Binance aggTrades, um 永续）,3 品种 × 最近 90 天。
> 挖掘限度：一只测量协议允许的最终主张 = "有/无增量 + 哪个特征";不许由此立刻生成交易策略。

## 1. 数据
- Binance vision `futures/um/daily/aggTrades/{SYM}/{SYM}-aggTrades-{date}.zip` × 90 天 × {BTC,ETH,SOL}USDT;
- K线 1h（同窗）用于结构/区域认知（沿用 fetch_binance_klines 的实现与 manifest);
- 记录每日行数与 sha256 摘要（分层：原始 zip sha，解开后仅按需柱效率抽使用）。

## 2. 接触点定义（因果窗）
在本研究认知上先跑结构：同一参数族的 ZoneBook 与事件探测（bar 级）;
**接触点 = 任一 E1/E2/E3/E6/E7 事件的 known_ts**（或 zone 当次正要触碰的 bar 收盘）;
评价窗：接触点前 60m 与后 60m 的 tape 切片（另设 ±15m 两档敏感性）。

## 3. Tape 特征（纯聚合，全部源于 aggTrades 行）
- `delta_share_{15,60}m` = (主动买-主动卖）/总名义
- `cvd_slope_60m` = CVD 斜率/总名义（60m);
- `big_share_15m` = Top-10% 交易名义额总占比（近 15m);
- `eff_15m` = |价格变动|/名义量（吸收签名：小 eff+大 vol = 吸收）;
- `vol15_rel` = 15m 名义量 / 过去 24h 15m 中位；
- 参照基线：同品种同 regime/方向下，随机 bar 对相同特征的分布（对照组构建同 §9 协议）。

## 4. 判别（写死在先）
- H1（可证伪）:接触点 tape 特征 (对拒绝方向）与后续 24h MFE/MAE 间存在稳定边际关系
  （特征分位切片后的净期望差 >0,block bootstrap CPI 不含 0);
- H2（吸收签名）:高 vol15_rel + 低 eff_15m 的接触 => 拒绝残幅显著厚于对照（两个亚假设，
  各自一个判别线，多重性保守裁判：两个都过才算“增量存在”);
- 分割：60d dev / 30d test;信息维度多比一次，每个亚假设各自的 test 一次。
- 样品量 <50 一律判 INSUFFICIENT_DATA。

## 5. 停止线
- 若两亚假设均未过 ⇒ bar 语义关于接触点的有限信息在本研究尺度已达穷尽 ⇒
  订单流路线就此终结，转前向纸面/L2;
- 若过 ⇒ 优势表述入机制资产（只表述度量，未成交易语义）；下一轮才是冻结协议的策略实验。

# 回撤的语义修复：风险身份、预算主体与主张生命周期（2026-11-03）

## 0. 结论

250U 生产链复利回放的 51.63% 回撤，**82.03% 来自峰值之后新开的交易**。这不是
"信号不够准"能解释完的：同一批行情里，系统把**一次市场判断**记成了多张独立仓位、
多份独立预算，并用**还没落袋的浮盈**当本金放大下一笔。回撤的深度由这三件事决定，
不是由某个阈值决定。

本轮做了其中一件（风险资本口径），实测有改善，但**只解决四个缺陷中的一个**，
重复下注比例仅从 36.1% 降到 35.3%。**不构成收益验收通过，也不代表实盘等价。**

同时否证了一个看起来最直接的方案：**"到对侧目标就平仓/保本"在数据上是负期望的**，
不能拿它冒充语义修复（见 §4）。

## 1. 事实基线（250U，全期，正常成本）

- 最大回撤 51.6270% / 6,183.8082U；峰 2026-02-06 01:00 UTC 11,977.87U，
  谷 2026-05-21 18:00 UTC 5,794.06U；2026-08-19 21:00 恢复。
- 峰谷按交易身份精确拆分：峰时已有 3 笔盈利仓回吐 −1,111.49U（17.97%）；
  峰后新交易净亏 −5,072.32U（82.03%）。
- 2026-04-29 → 05-07 连续 13 笔平仓亏损 −2,731.79U；05-04 单日 −16.18%。
- 回撤区间 107 个保护止损、11 个 v21 退出，**没有任何 `gap=yes`**；最大金额亏损与
  最差 R 都不是跳空退出。费用显著但不是唯一原因（毛实现 +2,451.47U、
  手续费 −1,338.42U、结算资金费 −73.59U）。

这些数字来自 `reports/compounding_250_20261103/`，已用未加观察器的原生链逐笔复跑核验。

## 2. 三个被量化的语义缺陷

### 2.1 同一市场判断被重复下注

597 次开仓中：

| 开仓时的账户状态 | 次数 | 占全部风险 |
|---|---:|---:|
| 同标的、同方向已有仓位（重复票） | 198 | **36.3%** |
| 同标的、反方向仍有仓位（自我对冲） | 90 | **16.7%** |
| 同标的上没有任何仓位 | 309 | 47.0% |

存活止损风险里，平均 **17.2%** 是"同标的同方向的第二张及以后"的重复敞口。
最坏小时同时持 10 条腿，合计止损风险 = 已落袋现金的 **37.6%**。

这不是"多周期共振所以更强"：账户天然只能承受一次价格移动。ETH 一根 4% 阴线会同时
打掉 ETH@2h/@4h/@12h/@1d 四个止损，四个止损各自记在四份预算里，但在账户上是**一笔**。

### 2.2 预算按"周期"复制，账户不是预算主体

`config/strategy.json` 每周期 12%、账户 50%。四个周期是**相加**的，合计 48%；
而 `capacity.RiskBudget.pools()` 在 `admission_full_cost` 的决策时刻**只返回周期池**，
账户池不参与。代码注释自己写着"账户池实际上从不生效"。

于是"账户最多同时亏多少"这件事**没有任何一处被定义**。预算单位是 `timeframe`
（一个观察时钟），不是"市场判断"，也不是"账户"。

### 2.3 本金口径自相矛盾

`current_risk_frac()` 用**已落袋现金**选档（≤1000U 5%、≤5000U 4%…），
`_fill_open()` 却用**含浮盈的盯市权益**算金额：

```
qty = risk_frac(cash) × equity_mtm / |entry − invalid|
```

峰值那一刻：现金 4,958.94U、浮盈 7,040.86U、权益 11,977.87U。档位按 4,959U 取 4%，
金额按 11,978U 算 —— 下一笔风险是"按现金算"的 **2.4 倍**。越浮盈、越下大注；
浮盈回吐时，仓位规模和权益同时下降，形成二次放大。

### 2.4 主张在完成后继续沿用旧证伪

REJECT 的 `target_1` 是对侧箱沿，语义上是"这次拒绝要走到对面"。460 笔带目标的
REJECT 中 **230 笔真的到过**。但代码里 target 只是锁利参考：

- 只有"管理 bar **收盘**越过目标"才 arming（`frac=-0.25`）；
- 没收盘越过就**从未 arming**，仓位继续用"本次试探极值"当止损，哪怕箱内行程早已走完；
- `time_stop=False`，没有"机会完成"这个状态。

结果：33 笔到过目标后转亏，合计 **−4,037.23U**（回撤区间内 9 笔 −1,618.49U）。
**"主张完成"与"仓位还活着"之间没有语义连接。**

## 3. 已实施：把"风险资本"和"偿付能力"分开

代码：`src/market_operator/broker.py`、`src/market_operator/campaign.py`。

- 新增 `Broker.risk_capital()` = 现金 − 已计提未结资金费；**不含浮盈**。
- `qty_for_entry(capital, …, notional_equity=…)`：风险金额用 `capital`，
  杠杆/名义上限用 `notional_equity`（盯市权益）。缺省参数保持旧行为，直接调用方不受影响。
- 成交（市价 `_fill_open`、挂单 `_fill_open_limit`）与**决策门**（`campaign` 准入）
  改成同一口径，避免"门按大权益放行、成交按小本金缩量"。
- 容量池的分母同样改用 `capital`（预算单位是风险，不是估值）。

新增 `tests/test_risk_capital.py` 5 条：浮盈不算本金、下一笔按现金定仓、
挂单同口径、缺省参数逐位不变、浮亏不改变"亏得起多少"（只压低杠杆上限）。
全量 **535 passed, 1 skipped**。

### 实测（同入口、同 250U、同行情、同配置）

| 场景 | 净收益 前 → 后 | 最大回撤 前 → 后 |
|---|---:|---:|
| full / 1x | 24,844.9 → **29,650.2** | 51.63% → **44.57%** |
| dev / 1x | 8,859.8 → 9,350.3 | 40.62% → 38.19% |
| test / 1x | 1,012.5 → 1,202.9 | 55.88% → **56.35%** |
| full / 1.5x | 15,917.6 → 18,154.7 | 64.00% → **57.68%** |

full/1x 回撤峰谷变为 12,107.61 → 6,711.70U；最大金额亏损 −675.89U 但仍是
**−1.1084R**（绝对金额随权益放大，R 未变）。

**必须如实说明：**
- 四项里三项回撤改善、一项（test）略差；**44–58% 的回撤仍然不可接受**。
- 这是同一条路径的重新定价，不是新的样本外证据；test 已被反复查看。
- 重复下注比例只从 36.1% 降到 35.3%，**结构问题没有动**。
- 该改动影响实盘定仓，尚未部署、未提交、未通过收益验收。

## 4. 被数据否证的"直觉修复"：到目标就平/保本

对 230 笔到过目标的 REJECT 做反事实（只重算这些仓的出场，不重跑复利）：

| 方案 | 受影响笔数 | 净收益变化 |
|---|---:|---:|
| 到目标后首次**收盘**回到入场侧即离场 | 64 | **−2,180.61U** |
| 到目标后**盘中**回到入场即按入场价保护 | 83 | **−3,403.99U** |

原因：147 笔到目标后**再没回到入场**，合计净赚 **+42,785.13U**。右尾就在"完成后继续
走"的那一段。所以"完成即离场"不是语义修复，是把趋势右尾剪掉。

这条负结果同时约束了后续设计：**不能**用"target 触价止盈 / 完成即保本"来包装成
"机会完成语义"。

## 5. 正确的语义契约（尚未实施的三项）

### C2 预算主体 = 市场判断，账户是唯一预算主体

- **现状**：`broker.positions` 以 `SYMBOL@TF` 为键，周期是仓位身份；四个周期池相加。
- **契约**：仓位身份是 `(标的, 方向, 结构来源, 几何版本)`；**周期是观察/裁决尺度，
  不是账户**。同一判断的多周期信号是**同一张仓位的再确认/加仓**，不是新仓位。
- **预算**：账户占用 = Σ 所有在仓判断的当前最坏损失；周期池只能是账户预算内的
  **分配份额**，不能相加成 48%。`admission_full_cost` 在决策时刻跳过账户池的特例要取消。
- **验收**：同标的同方向风险不再叠加；账户最坏情景占用不再随"周期数"线性放大。
- **否证条件**：若收益右尾主要来自这些重复票（即重复是承重的），说明"多周期独立"
  承担了信息，而不是重复下注 —— 那就必须显式承认它并单独定价，而不是假装独立。

### C3 相反主张不能同时成立

- **现状**：同标的多空可同时持有；408 个回撤小时里存在相反腿，全期 2,118 小时。
  净敞口为零，费用与止损风险翻倍。
- **契约**：对同一标的，"会涨"和"会跌"不可能同时为真。新主张与在仓主张相反时，
  必须**先了结旧主张（反手）**或净额化，不能两张票各记一份预算。
- **验收**：相反腿并存小时数 → 0；同样的行情下费用与预算占用同时下降。
- **否证条件**：若净额化后收益明显下降而回撤不变，说明"双边持有"实际在做波动率
  而非方向，那要按波动率主张重新定义，而不是继续按方向预算记账。

### C4 主张生命周期：完成 → 重新承保，而不是自动续期

- **现状**：REJECT 完成后没有状态变化，继续用"本次试探极值"当证伪价；`time_stop=False`。
- **契约**：每个仓位必须绑定一个**仍未完成且未被证伪**的主张：
  `OPEN → COMPLETED | FALSIFIED`。完成（到对侧）后，原来的"边界拒绝"主张已经用尽；
  继续持有必须由**新的迁移事实**（外侧连续收盘、结构位移、新的几何版本）重新承保，
  且证伪价必须换成新主张的 —— 不能再拿旧试探极值当"趋势仓止损"。
  没有新主张 ⇒ 结束，但**结束方式必须由 §4 的负结果约束**（不能简单按目标价平）。
- **实现位置**：`position.py` 的 `on_bar` 目标段与 `opp_lock_step`；`events/routing`
  提供迁移事实与几何版本。
- **验收**：完成后无新主张的仓位不再占用旧试探风险；到过目标后转亏的 −4,037U 必须
  被解释为"重新承保失败"而不是"运气不好"。
- **否证条件**：若"完成后重新承保"的收益低于"什么都不做"，说明当前右尾来自
  未定义的持有惯性，应如实记录为未解释收益，不能用它证明契约有效。

### C5 证伪价必须属于同一几何版本

- 箱体退役/重建不自动取消合法突破主张，但旧主张的止损不能引用新几何的价位；
  反之新主张也不能继承旧证据。这是 `box_id` + `geometry_version` 的绑定问题，
  已在 `docs/balance-semantics-20261103.md` 记录，尚未实现。

## 6. 为什么这不是门槛/过滤/参数

- 没有新增任何数值阈值；`risk_frac`、档位边界、12%/50%、`frac=-0.25` 全部未改。
- 改的是四个定义：**什么算本金**、**什么算一份预算**、**什么算一张仓位**、
  **一个主张什么时候还活着**。
- 没有任何"亏损区间不交易""加确认根数""提高冲量要求"式的规避。
- 每一项都给出否证条件，允许结论是"我错了"。

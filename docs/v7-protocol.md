# v7 研究协议（冻结于任何 v7 运行之前，2026-10-19)——照抄验证 quattro 复刻

> 依据：docs/audits/oss-hunt-3.md。目的单一：把上游 MIT 许可、自称现场存活的
> quattro(Donchian 20-bar close 突破，长-only BTC 4H，日级 EMA200 上坡过滤，+0.5N×4 加梯，
> 2N 单位棘轮，Donchian(10) 出场，5% 账户强平），**逐字语义、零改动**复刻进我们的成本/记账引擎，
> 在同 venue、同成本模型、同 2024-10→2026-10 数据上跑赢跑输。**它不是 market-operator 的候选语义，
> 是对照实验**：裁决"本场座是否必死"与"金字塔/跟踪器官移植是否值得"。

## 1. 规则逐字（以上游 README §2 与 backtest.py 为准据）

- 标的：BTCUSDT 永续 4H（本地带哈希聚合帧）；方向 long-only。
- 入场：close > 前 20 根 high（不含当前，rolling().shift(1)) 且日 EMA200 > 20 日前值 ⇒ 次 4H 开盘市价。
- 加梯：N=入场时 ATR(14) 固定；unit2@+0.5N、unit3@+1.0N、unit4@+1.5N(wick 触及即于次开盘加）;
  每单元风险=2% 账户、初始止损=单位入场−2N；合计最坏情景 5% 账户硬强平；杠杆沿用系统 cap。
- 出场（先触发先算）:(a) close < 前10根 low ⇒ 全部单元次开盘平；(b) 单元级棘轮：最近单位入场−2N（只在新加仓时收紧）;(c) 5% 硬强平。
- 成本：taker 0.06%/边 + 滑点 0.02% + 资金费按持仓时长计价（系统同模型）；无 maker 优惠（次开盘成交）。
- sizing 舍入/最小单：沿用系统 broker(Bitget 合约规格）;300 USDT 下若 min_size 拒单如实记。

## 2. 评估

- 纯对照：与上游自报区间不同——我们只有 2024-10→2026-10(2 年），如实声明覆盖差异；
  不主张复现 +1107%。判定口径：本数据窗内净值、PF、回撤、单笔质量与 exit 三分桶占比
  （上游:40% hard stop/36% Donchian/23% trailing)。
- A/B 等价性自检：先跑上游自报同款窗口所需的历史不可行 ⇒ 只做内部一致性（逐条规则断言）
  与上游公开 trades 形态对比（若有）。
- test/dev：本轮为**对照实验不入我们的评分体系**，但仍按时间顺序复放，结果只回答
  "同主场同周期，照抄规则是正/是负";若为正，再立项移植（那将是 v8 的独立协议）;
  若为负，照抄验证本身完成，不追调。不重置、不调参、不优化——照抄就是照抄。
- research-log 条目 13 先行登记。

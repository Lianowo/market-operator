# 投入/结果扩展协议（2026-11-02）

本轮为前研究后续探索，不能称独立验证。固定6候选+baseline/accept_only，dev/test/full×1x/1.5x，共48场景，无连续阈值搜索。不承诺全局最优，不自动部署。

## 入场与对照

15m和30m各3候选：price替换2h REJECT、effort替换2h REJECT、effort_add保留所有原入口只在空闲战役补充。其余周期、风险、手续费、历史资金费、保护止损与2h后续管理不变。共同15m执行，初始300U、权益风险0.75%，四币。

最近在触发K线开盘前收盘2h的ACTIVE BOX_EDGE冻结边沿、ATR、对侧目标。前低周期收盘在箱内，本根区间进入边沿，开启观察；边沿身份为角色+origin_known。最多4根当前低周期K线含首次触边允许收回，超时或目标已过锁定；边沿身份消失删除。等到整根离内沿回箱内>=0.3当前2h ATR才复位，下一根方可再测。

仅首次收盘回内沿的K线可选：收盘沿反转方向收阳/阴且位于同方向全区间65%以上。无论价格/量能/成本/仓位容量是否通过，都消耗此机会。不在失败后挑后续好K线。若触边当根收回，当根即可确认，不等2h事件、不等反向端点突破。未收回前可以刷新测试极值。

全部候选预热此前24h完整已收盘同周期K线。rvol=V/过去V中位数；relative_range=(H-L)/过去(H-L)中位数；effort_ratio=rvol/max(relative_range,0.25)。当前K线不进入自身分母。effort组额外要求effort_ratio>=1.5且rvol>=1；只表示单位价格区间的成交投入较高，不等于真实吸收。保留外侧推进<=0.1ATR且外向实体<=0.1ATR，在已收回且反向实体的价格集合内属显式冗余约束，不宣传为独立量价证据。

止损为本轮测试极值外0.1冻结2h ATR；目标为冻结对侧内沿；收盘距内沿向箱内<=0.5ATR，剩余RR>=1.5，名义往返成本0.0016×价格/风险<=0.25。收盘确认后下一15m开盘执行，跳空滑点后的目标/RR仍由broker检查；距离/名义成本只在决策收盘检查。

## 选择与验证

先全部dev完成冻结选择，之后历史test/full不重新选冠军。两档成本均需：新成交已平仓>=20笔；组合净额高于baseline和accept_only；DD<=baseline110%；新成交净亏且保守MFE<0.5R比例<=baseline 2h REJECT同指标+3个百分点；dev按固定2h时间范围中点两半，各自新入口净额均>0。合格候选按dev1.5x组合净额最大选一名。无人合格保留baseline，不改门槛。

选中者历史test两档成本新成交>=10，并满足同样净额、DD、失败代理门槛才算历史复核通过，仍需新的独立数据才能考虑部署。历史test被反复研究，不是新的独立样本外。

验证同周期price原始机会与effort信号/拒绝为同集合、同价格/止损/目标/时刻，effort与effort_add生成流相同。下一15m开盘、0.5R/止损12h代理仅辅助辨别过滤代价，同根先止损；不要混同真实持仓收益。增量入口可能占用原信号槽位，因此保留原入口不等于原成交不变。多个实验产生的选择偏差无法用反复查看历史test消除。

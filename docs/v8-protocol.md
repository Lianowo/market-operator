## 1. E8 EDGE_RECLAIM 定义（逐字冻结）

**语境**:current confirmed band `B=[L*,H*]`(last confirmed pivot low/high);
位置 `pos=(close−L*)/(H*−L*)`。**边缘带先验：多头候选需 pos ≤ 0.20（底带/折价区）,
空头候选需 pos ≥ 0.80（顶带/溢价区）**——数值为摆动带三等分取整前的先验，敏感性仅 dev
{0.15, 0.25}，不上 test。

**触发（多头）**:bar 刺穿支撑语义区（沿用 E2/E3 的区域触碰判据）后在 ≤N_f=3 根内
收盘收复回 `zone.lo` 之上且当时 pos≤0.20 ⇒ 于该收盘发事件 E8|long。
空头镜像：刺穿阻力区+收复回 zone.hi 之下且 pos≥0.80 ⇒ E8|short。
**入场**=次 1h 开盘市价（单执行风格，保证与 v6 桶可比）;
**失效**=刺穿极值 ∓(k_bm·atr),F1 ≥0.8·atr 天然距离不足即无交易；
**目标**= 对侧结构边缘（多 ⇒ H*, 空 ⇒ L*),room<r_min·risk 拒；
**出场**=§8 全套沿用 canonical(turtle 收割语义同 canonical)。
同时每 (symbol,TF) 战役规则、组合容量、budget 与 canonical 完全一致。

**与 E5 关系**:E5(RANGE 合成带边缘回归）从未脱离事件目录；E8 吸收其语义，
以"摆动带边缘+收复确认"的更可检验形式重表达，E5 仍保留侦测但 v8 白名单不含 E5。

## 2. 评估

- dev 主评估：E8|long / E8|short 逐（TF×机制）桶：笔数、胜率、平均R、净额；
  对照桶 = 同期 canonical E6/E7 同尺度结果（位置语义的 A/B);
  位置带敏感性 {0.15/0.20/0.25} 仅报 dev 稳健性，不择优。
- test：一次性（第 11 次曝光，research-log #14；此后任何迭代只许前向）。
  升级线不变：test≥60 且 1.5x 净期望>0 且 2x PF>1。
- 判别量（写作在先）：若位置假说成立，E8 桶的入场 pos 应集中于边缘带（构造的），
  且胜率显著高于同尺度 E6/E7 桶（位置→胜率的因果链);若 E8 入场 pos 集中了但胜率无差异,
  则"位置坏"命题对 E8 家族被证伪——如实判。

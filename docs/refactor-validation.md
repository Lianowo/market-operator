# 结构收束与验证边界

## 行为基准

当前收束的策略基准为提交 `49c066fed7bb2946d92529a6465380db41113a2d`。
不通过调参、刷新冻结基线或放宽收益判据抵消重构差异。

精确对照命令(仓库根目录):

```powershell
python tools/verify_strategy_parity.py --ref 49c066f
python -m pytest -q
git diff --check
```

对照工具在独立临时源码树和独立解释器中执行历史实现与当前实现,共享本地行情、
资金费和合约规格,对逐笔交易全部字段、完整净值序列、计数器做不截断精度的
JSON SHA-256 比较。默认覆盖四标的、三个数据段、两档成本。
它不连接交易所、不启动实盘、不覆盖历史收益下界验收基线。

## 不应误删的内容

- 历史协议、研究报告、数据 manifest 和包版本有各自的溯源/发布用途,不是退役运行代码。
- `invalid0` 仍用于真实成交回执校正初始风险,并非旧分桶遗留状态。
- 观察挂单近触反弹确认仍产生 `VIRTUAL_TRIGGER`、`virtual_limit` 和相应计数器;
  不应因名字与历史实验相似就删除或改名。
- 精确回放通过仅证明覆盖数据与配置下的输出一致,不能替代实盘外部交互验证,
  也不能证明所有可能行情/配置下的形式化等价性。

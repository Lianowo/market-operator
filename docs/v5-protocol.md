# v5 研究协议（冻结于任何 v5 运行之前，2026-10-19)——最终形态，最后一轮

> 动因：v4 反事实测量（reports/v4_counterfactual, PR#5)：过期限价单若市价化 n=20、胜率75%、+41.2 USDT——
> **错过的正是不回踩的强延续**；而 v4 已成交侧限价优于市价。结论：限价与市价各有其场景，
> 普适规则两个方向都错，**正确语义是按破位质量路由执行**。本轮为最终形态整合，跑完即定版。

## 1. v5 唯一变更：破位质量路由执行（不强加任何新价格条件）

全部沿用已冻结语义与先验：事件 E1/E6/E7、区域生命周期、F1(k_is=0.8)、§8、k_bm、r_min、N_fill=12、成本模型。
白名单仅 **short**——long 侧在所有轮次增量期望均为负（无信息规则：含信息的机制才保留），如实声明。

决策状态机（每品种一仓/一挂单，满仓或挂单中不再武装新信号）:

1. **E6|short（破位当下）**：计算破位质量（仅入场时刻已知的量）:
   - `margin = (破位价 l_star − 收盘)/atr`, `impulse = 破位bar振幅/atr`。
   - **STRONG**:`margin ≥ k_dq` 且 `impulse ≥ k_imp` ⇒ **市价，下一根 1h 开盘**。
     **先验 k_dq=0.5, k_imp=1.5**（新先验：位移半条 ATR + 冲动一根半 ATR；只做 dev 敏感性
     {k_dq 0.35/0.75, k_imp 1.25/2.0}，不许上 test 择优）。
   - **WEAK**：不入场，不撤语义——让该 episode 的区域生命周期继续；若其后 E7|short
     （回踩拒绝+角色互换完成）于同 episode 触发 ⇒ 按 v4 G3 **挂区域前缘限价单**, N_fill=12。
     超时=没有这笔交易（接受错过；错过成本已被 v4 反事实量化，此路损失已被 strong-E6 优先捕获对冲）。
2. **E1|short（突破接受）**：永远 **市价** 下一根开盘（接受本身即质量证明）；E1 信号出现时若有
   该品种的挂单或持仓 ⇒ 挂单取消（E1 优先级最高）。
3. 全部入口统一 **F1 距离下限**（补齐 v1 闸口缺陷：E1/E6 同样适用）。
4. §8 出场、风险预算、杠杆/MIN_SIZE、费用（maker/taker 非对称）与 v4 一致；执行路径仍 15m。

## 2. 评估（一次性，同构判据）

- dev：跑通+敏感性（仅观察稳定性，不改先验）;test 段评估计数：第 7 次且最终（research-log #10)。
- 9 段 × 成本 1x/1.5x/2x；强制分组报表：strong-E6 / weak-E7 / E1 三桶各自的笔数、胜率、平均R、净额——
  路由假设的判别证据就在桶间差异。
- 升级线（不变）:test ≥60 笔 且 1.5x 成本净期望>0 且 2x PF>1 ⇒ 才谈 forward dry-run;
  否则维持 Research Only，**两种结局都关闭协议级优化循环**。
- 诚实预期（先声明）：按历年成本算术，乐观上限约打平至小赚；本次实验的价值是判别
  "破位质量是否携带路由信息"（桶间差异是否显著），而非承诺转正。

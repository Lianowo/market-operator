# v11 研究协议（冻结，2026-10-20)——跨 episode 区域发育（归因测量）

> 命题："过程"长在区域的履历上，不在单次 episode 里：区域被反复触碰时，防守是
> 衰减（被摸烂）还是累积（供给业愈堆愈厚）？bar 全部装得下，零数据新成本。

## 1. 测量对象（事件检测零改动，只读其输出）

对每 (symbol, observation TF=1h) 重放结构层，登记**每区域的每次触碰**(A2/A3 语义）,
记下履历快照（全部因果）:
- `k`:第 k 次触碰序数；`age_days`:区域自 origin 至此的天数；`role`/`merged`;`regime`。
- `dwell_k`:本次 episode 连续滞留 bar 数（自触入至首次整根脱离正面侧）。
- `pen_k`:向区域外缘刺入幅度（极值-缘）/atr(touch)。
- `out_rj_k`:触碰结束后 24 根内，**拒绝方向**最大有利位移（ATR)。
- `out_br_k`:同窗内，**破位方向**最大位移（ATR)。

## 2. 判别（写死在先，不许挪）

- 主判别：k（或 log k）与 `out_rj_k` 的**秩相关（Spearman)**与自助 CI;
  - 衰假说：corr<0 且 CI 不含 0（越摸越薄）；**厚假说**:corr>0（可能流动性累积）。
- 次判别（checker 上证）：按 k 分桶（1/2/3/4/≥5）给出桶均 out_rj/out_br 及存活率
  (24h 内是否被 acceptance 破位）；论"k-新鲜区防得住"须同时过两判别。
- dev 迭代与调表，test 段一次（曝光 #14,log#22)；数据单元=zone-touch，声明。

## 3. 若签名成立——预注册的路由用例（不事先宣扬生效）

- 区域"新鲜度"将进入**假设层元数据**（方向无关的事实字段）:
  - k ≤ k_* 的区：边界拒绝类假设按原语义可用（位置语义应得的场景）;
  - k > k_* 的区：失效/目标换更宽布置（供给已疲）,E1 类破位假设**不再加分**。
- k_* 从 dev 分桶的断点冻结（候选 {2,3},dev 判定，不同择优上 test)。
  **这是语义修复，不是过滤名单**——只改该情境下的失效/目标布置与说明。

## 4. 非目标

不动现有检测/收割/费用；不引入新事件 id；不宣称签名有效直到判别通过；
若主线判别两假说都不成立 ⇒ 结果是"区域履历不含方向信息"，如实得出，不做再联想。

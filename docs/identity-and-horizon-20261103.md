# 身份与有效期：C5 / C6 的研究结论（2026-11-03）

## 0. 两句话答案

- **C5**：现在的"身份"是 Python 对象地址（`id(z)`）加价格近似。必须换成
  `claim_id = (box_id, 方向, geometry_version)`，其中 `geometry_version` 由**结构事件**
  （合并/重建/翻转/退役）递增，不由浮点差比较产生。分三步做，第二步必须做到
  **回放逐位不变**才算接对。
- **C6**：主张的有效期**不是时间**，而是三个事件中先到者：**完成、证伪、结构退役**。
  时间止损是在用参数替代事实，而且在冻结样本上会剪右尾。要证明"退役"是主因，
  先做 §4 的决定性实验；在实验之前不引入任何有效期数字。

---

## 1. C5 的现状：身份确实是错的（可核对）

| 事实 | 位置 | 后果 |
|---|---|---|
| `Zone` 没有 `box_id` 字段 | `structure.py` §`class Zone` | 箱体身份在桥接处丢失 |
| `BracketLevel` 有 `box_id` | `true_balance.py` `bracket()` | 上游知道身份，下游拿不到 |
| 新建 Zone 不传 `box_id` | `structure.py` `nz = Zone(...)` | 每根 bar 都可能造"新箱" |
| 身份键是 `id(z)` | `structure.py`/`events.py`/`trigger.py` 共 20+ 处 | `clone()` 后身份变了：事件里 `zone.clone()` 与结构里的 `z` 永远不是同一个 |
| `_broken`、`_adopted_retests`、`live_ids` 都用 `id()` | `trigger.py` / `structure.py` | 重建/克隆后"已破位"记录失效，可能重复开同一机会 |
| 路由复位按取整边界价 | `routing.py` `zone_departure_reset` | 边界微移 = 新机会；真实换箱 = 旧证据 |

这不是"风格问题"。用 `id()` 做键，等价于**用内存地址当市场机会的编号**：
对象一重建，同一个箱就是新机会，同一机会也会被当成两个。

## 2. 目标数据模型

```python
@dataclass
class Zone:
    ...
    zone_uid: int = 0              # 构造时分配，单调、永不重用（无 box 时的兜底身份）
    box_id: Optional[int] = None   # 来自 TrueBalanceBox（跨重建稳定）
    parent_box_id: Optional[int] = None  # FLIP 后的来源箱
    geometry_version: int = 0      # 边界集合发生"结构事件"时 +1

    @property
    def claim_id(self) -> tuple:
        return (self.box_id if self.box_id is not None else ("uid", self.zone_uid),
                str(self.role), self.geometry_version)
```

- `zone_uid` 由结构对象自增分配，`clone()` 原样复制；**绝不使用 `id()`**。
- `box_id` 从 `BracketLevel.box_id` 透传（上游已有）。
- `geometry_version` **只在结构事件处 +1**：合并（多条水平并一条）、重建（同 id 新边界）、
  翻转（BROKEN_UP/DOWN 后重挂）。不做 `abs(lo - old) > tol` 这类浮点比较——
  那会把"报价抖动"当成"换箱"，又会引入一个容差参数。

## 3. 五条不变式（每条都能写成测试）

1. **同一箱，跨重建同 id**：`TrueBalanceBox` 重建走 `_evaluate_span(box_id=box.box_id)`，
   Zone 必须继承该 id。
2. **同一 id + 同一 version ⇒ 同一主张**：可以复用 episode/候选/破位记录。
3. **同 id + 不同 version ⇒ 不同主张**：旧证据不得偷渡（这正是首轮审计里
   "旧 ref + 新 zone" 的错误）。
4. **`clone()` 不改变 `claim_id`**：事件携带的是事实快照，不是新机会。
5. **退役即失效**：箱体进入 DEAD/被替换后，`is_live(claim_id)` 为 False；
   持仓必须按 C6 处理，而不是继续引用旧止损。

## 4. 分三步实施（每步独立可验收）

### 第 1 步：只加字段与透传（行为不变）

- `Zone` 增字段；`clone()` 复制；`nz = Zone(...)` 传 `box_id=getattr(lvl, "box_id", None)`；
  合并分支保留最早 `box_id` 并 `geometry_version += 1`。
- 事件 `attrs` 增加 `claim_id`；`routing` 写进 `OPEN` meta；`Position` 存 `claim_id`。
- 验收：**回放结果必须逐位不变**（只加字段不改判断）。
  这是"接对了"的最强证据：如果逐位变了，说明有不该动的地方被动了。

### 第 2 步：把 `id(z)` 换成 `claim_id`

- `structure.zones` 的存活判断、`events` 的 `previous_edges`/`live`、
  `trigger` 的 `_broken`/`_adopted_retests`/`live_ids` 全部改键。
- 验收：**再次要求回放逐位不变**。键的类型变了而结果不变，说明旧代码里
  `id()` 恰好等价于"对象在本次 bar 内不重建"——这本身就是一个可验证的断言。

### 第 3 步：让身份产生行为（C6 的入口）

- `is_live(claim_id)` 由结构层提供；持仓每根认知 bar 查询：
  `version` 变了或箱体退役 ⇒ 主张不再是当前主张 ⇒ 必须重新承保或平仓。
- 验收：不再出现"持仓引用的几何版本已不存在"的情况（可用指标：
  每个持仓在其持有期内是否始终 `is_live`）。

### 防护与失败模式

- **重建保 id 但边界变了**：必须 version+1，否则旧候选沿用旧边界。
- **多条水平合并**：保留最早 id，version+1，避免"合并即新机会"。
- **FLIP**：`parent_box_id` 指回原箱；`source_kind=FLIPPED_BOX_EDGE` 与新 id 绑定，
  不允许旧突破候选跨 flip 继承。
- **同一价格两个箱**（价格近似但 id 不同）：按 id 分开，不许按价格合并。

## 4. C6：主张有效期

### 4.1 为什么"时间止损"是错的（两条独立理由）

1. **它必然引入一个数字**（N 根 bar / N 小时）。这与本轮"不靠参数"的标准冲突，
   而且这个数字会在不同周期上不可比。
2. **它会剪右尾**。冻结样本上，"到目标即平/即保本"已经实测为负
   （−2,181U / −3,404U）；时间止损是同一类剪法的变体。

### 4.2 正确定义：有效期由三个事实决定，不由时钟决定

一个主张在下列任一事实发生时失效：

| 事实 | 判据 | 现状 |
|---|---|---|
| **完成** | 价格到达主张声明的目标（对侧边界） | 本轮已实现（§2.5），改风险基准 |
| **证伪** | 收盘越过该主张自己的失效价 | 已实现（§8.1 + 保护止损） |
| **退役** | 产生该主张的几何版本不再是当前版本（箱体重建/替换/DEAD） | **缺 C5，无法判断** |

在这三个事实之外，"持有了多久"不构成任何信息。12h/1d 的亏损**看起来**像"拿太久"，
但真正的变量是：持有期内，产生该主张的那个箱**是否还是同一个箱**。
如果箱体早已重建而仓位还在引用旧边界，那不是"时间太长"，是"主张过期未被发现"。

### 4.3 决定性实验（先做这个，再决定要不要规则）

在 C5 第 1 步（只加字段）完成后，用只读回放记录每笔交易的：

- `claim_id` 与持有期内出现的 `geometry_version` 序列；
- `is_live` 在退出前是否变为 False；
- 退出原因、R。

然后分成两类：

| 类别 | 若占比高，说明 | 应采取的动作 |
|---|---|---|
| 退出前主张已退役/换版 | 亏损来自"过期主张" | 退役即平仓/重新承保（语义，无需数字） |
| 退出前主张始终有效 | 亏损来自"主张本身错" | 不能用有效期解释；要查入场价与剩余行程 |

**判定标准**：若"已退役"类在 12h/1d 亏损单中占多数（例如 >60%），则 C6 落为
"退役即失效"规则；若占少数，则**不做**有效期规则，转为研究"入场时剩余行程"。

### 4.4 不做的事

- 不引入时间止损/最大持有根数；
- 不用"同一主张只允许 N 次重试"这类计数门槛；
- 不在 C5 之前改任何与身份有关的判断。

## 5. 已有证据的支持与边界

- 支持"身份有问题"：`id(z)` 做键 20+ 处；`Zone` 无 `box_id`；`zone.clone()` 进事件。
- 支持"时间不是主因"：12h/1d 期外同样持有 72–120 小时，却是全样本最好的周期；
  期内持有期没有显著变长（12h：72.5h → 51h），真正变的是环境（漂移翻转）。
- **尚不能证明**"退役是主因"：需要 §4.3 的实验。本轮不把推测写成结论。

## 6. 本轮已顺带修掉的同类语义错误

- **同一原语两层覆盖不同**：触发层此前只在破位时移除 episode，没有 `outside_closes`
  证据，因此永远不会产生 R3 失败突破回收；认知层有。现已补齐，并加了两条测试
  （`test_trigger_layer_r3_uses_the_same_outside_close_evidence`）。
- 这是"同一事实在两处实现不同"的典型：不涉及任何参数，只涉及事实覆盖。
- **实测影响：0**。补齐后同一入口重跑 250U，四个场景与补齐前逐值相同
  （full/1x 14,593.914041、528 笔、DD 49.0823%），说明该路径在这段数据上
  没有产生过可判定的 R3（而不是"规则无效"）。报告：`reports/semantic_repair_v2_20261103/`。
  这也说明：要在回放里看到它，需要先让触发层 episode 真正积累 `outside_closes`
  （当前 episode 在破位时即被移除），这属于 C5 的身份/生命周期问题，不是本处的覆盖问题。

### S1 · C5-2：把 `id(z)` 换成 `claim_id`（已完成）

- **实际范围比原估小**：`id()` 共 21 处，但**跨 bar 的持久记忆只有 2 处**
  （`trigger._broken`、`trigger._adopted_retests`）；其余 17 处是"同一调用内的对象查找"
  （`previous_edges`、`live`、`alive_ids`、`_accept_refresh_only`），用对象身份是正确的。
- 结果：两处改为 `zone_id`（box/uid + role，不含几何版本）。
- 回放变化（相对 C5-1）：full 14,593.9 → 14,243.6；dev 3,823.1 → 3,573.9；
  test 1,269.5 → 1,438.6；1.5x 7,764.6 → 8,394.0；DD 不变。
- 解释：变化只能来自"已破位的箱在对象重建后仍保持破位"。此前合并/重建会重新武装
  同一只已破的箱，现在不会。方向不统一（有增有减）是正常的：它既删掉了一批重复武装，
  也改变了后续可用信号。

### S2 · C5-3：退役即失效（**数据否决，不启用**）

- 已实现事实层：`ZoneBook.is_live(claim_id)` / `Structure.is_live`，只回答"该几何版本是否仍当前"。
- 已跑决定性实验（`docs/c6-experiment-20261103.md`）：525 笔中仅 **24.6%** 在退出前退役；
  亏损单中退役占比 15.5%–32.9%，远低于预设的 60% 门槛；而且**退役组的平均 R 更高**
  （0.694 vs 0.196）——退役多半是价格走出去的结果，强制平仓会在趋势起点砍仓。
- 决定：**不接入平仓决策**。`is_live` 保留为事实查询，留给"重新承保"或诊断。

### S3 · C6：主张有效期（结论已定）

- 结论：有效期 = 完成 / 证伪 / 退役三事件；**退役不构成处置理由**。
- 不引入时间止损、最大持有根数；下一次研究目标转为"入场时剩余行程/赔率结构"。

### S4 · 一主张一票（发现前置缺陷，暂缓）

- `TrueBalanceBox.box_id` 由**每个 (symbol, tf) 的检测器实例**各自从 1 开始分配，
  因此 `box_id` 只在单个 campaign 内唯一；跨 campaign 直接比较会**伪碰撞**。
- 要做"同 claim_id 只一张票"，必须先给身份加命名空间（campaign key 或全局分配器）。
- 本轮不做：现在没有任何代码跨 campaign 消费 `claim_id`，贸然加命名空间会制造第二套口径。
- 结构层提供 `is_live(claim_id)`；持仓每根认知 bar 校验：
  版本变化或箱体退役 ⇒ 主张过期 ⇒ 必须重新承保（同向迁移事实）或平仓。
- 验收指标：**持有期内 `is_live` 恒为真**；`geometry_version` 变化必须伴随一次重新承保。
- 否证：若"退役"在亏损单中占比很低，说明过期不是主因，停止这条、转 S3。

### S3 · C6：主张有效期的决定性实验（先实验，后规则）
- 记录每笔交易的 `claim_id`、持有期内版本序列、退出前 `is_live`。
- 判定：若"退出前已退役/换版"在 12h/1d 亏损单中 **>60%** ⇒ 立"退役即失效"；
  否则**不立**有效期规则，转研究"入场时剩余行程 / 赔率结构"。
- 不引入任何时间阈值。

## 4. 每一步的失败模式

| 步 | 可能的失败 | 处理 |
|---|---|---|
| S1 | 回放逐位变了 | 回退该处键替换，先证明旧行为等价，再前进 |
| S2 | 退役判定过频，收益骤降 | 查"退役"是否把正常边界刷新当换箱（version 语义），不改参数 |
| S3 | 退役占比低 | 不立规则；记录为"无需有效期"，转向赔率结构研究 |
| S4 | 一并票导致容量利用率下降 | 记录为语义代价；不得靠加大风险补偿 |
| S5 | 更早止损使结果变差 | 这是正确性；若变差，说明原先的"保护缺口"在贡献收益，需如实记录 |
